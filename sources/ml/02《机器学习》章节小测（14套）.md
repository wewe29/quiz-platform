### 参考答案与解析（第1章 A卷）

**一、单选题**

1. **答案：D**
   解析：课件原话是「学习能力：认知的基石——从海量数据中提炼规律，构建对世界的底层认知框架」；「迁移能力：进化的翅膀——将习得的经验灵活应用于全新的未知场景，实现举一反三」（001 P2）。B 把两个比喻对调了，这是本章最容易记反的一处，记忆口诀是「先学后迁，先基石后翅膀」；C、A 说的是数据与算力、算法与模型的关系（001 P8、002 P10），与智能的两要素无关。

2. **答案：A**
   解析：课件原句为 "Machine learning is the field of study that gives computers the ability to learn without being explicitly programmed." —— Arthur Samuel (1959)（001 P7）。拆开看有两个关键限定：**learn without being explicitly programmed（无需显式编程）** 与 **learn（从数据中学习）**。B 恰恰是课件批判的「规则驱动（符号主义）」路线；C 描述的是 AGI 的目标而非机器学习当前的定义；D 属于「暴力计算」的比喻层面，不是该定义的落点。

3. **答案：D**
   解析：课件给出的三大阶段局限是一一对应的：机器学习阶段「依赖人工特征工程，难以突破经验边界」；深度学习阶段「专用智能，缺乏跨任务的推理与迁移能力」（001 P11）。本题的坑就在 C——它是**深度学习阶段**的局限，答 C 就等于把两个阶段的局限张冠李戴。B、A 均无课件依据；算力不足恰恰是早期路线失败之外的因素，课件强调的是「规则写不完」而非算力不够。

4. **答案：B**
   解析：课件定义 $w$ 为「权重 (weight，斜率)——面积每增加 1㎡，房价变化多少」（003 P1），即**边际变化量**；$b$ 为「偏置 (bias，截距)——当面积为 0 时的理论基准值」。A 是 $b$ 的含义、C 是预测值 $\hat{y}$、D 是误差 $\hat{y} - y$。易错点：把 $w$ 理解成「房价」而不是「房价的变化率」，后面讲梯度下降更新参数时就会全线错位。

5. **答案：C**
   解析：$MSE = \frac{1}{n} \sum (\hat{y} - y)^2$，三步是「逐样本算误差 → 取平方 → 求平均」（003 P1）。A 是平方误差之和（未平方、未平均）；B 是绝对损失函数的形式（见 01 P23）；D 既无课件依据，形式也不成立。考点陷阱是「平方」和「平均」两个动作缺一不可。

**二、多选题**

1. **答案：ABC**
   解析：课件明确列出「01 海量数据 (Data)」与「02 超强算力 (Compute)」，并以「数据为 AI 提供『养料』，算力为 AI 提供『引擎』……缺一不可」作结（001 P8），A、B、C 均是该页原文的展开。D 错在因果：早期规则驱动（符号主义）的困境是**规则写不完、现实充满变数、难以泛化**（001 P7），而不是算力不足；恰恰相反，课件认为算力是 AI 最近才补齐的拼图之一。

2. **答案：DB**
   解析：课件给出的两个好处是「消除正负号的影响——让误差绝对值化，防止求和之后正负误差互相抵消」与「放大误差便于优化」（003 P1），故 D、B 正确。C 无依据：MSE 前面带 $\frac{1}{n}$，本身就依赖样本量；A 也无依据，且与第 2 章「样本不足会过拟合、需正则化」的结论方向相反——MSE 本身并不能防止过拟合。

3. **答案：ABD**
   解析：课件逐一给出四个权重的符号直觉：$w_1$（面积）➕ 正、$w_2$（楼层）➕ 正、$w_3$（距地铁）➖ 负、$w_4$（房龄）➖ 负（003 P1）；$b$ 是「面积为 0 时的理论基准值」。C 错在符号与语义同时反了——离地铁越远房价越**低**，权重应为负。记忆技巧：与「资产价值正相关」的特征（面积、楼层）权重为正，与「房屋折损正相关」的特征（距地铁、房龄）权重为负。

**三、简答题**

1. **答案要点**：
   ① **学习能力 = 认知的基石**——从海量数据中提炼规律，构建对世界的底层认知框架，是智能产生的源泉；**迁移能力 = 进化的翅膀**——将习得的经验灵活应用于全新的未知场景，实现举一反三，是智能进阶的关键（001 P2）。二者合成课件给出的**智能的本质公式：智能 = 学习能力 + 迁移能力**（001 P4、P15）。
   ② **泛化的定义**——从具体案例中抽取共性规律，将过往经验迁移到全新的、未见过的情境中，做出正确判断的能力；课件把它称为智能的「核心」（001 P4）。
   ③ **「举一反三」现象**——孩子被开水烫过一次后，不仅会避开那个杯子，还会警惕所有冒热气的物体；无需亲自尝试所有危险，便能从有限经验中总结规律、对未知场景做出预判（001 P4）。
   **评分提示与易错提醒**：只写公式不给两个要素的含义，最多得一半分；把「泛化」写成「记住更多样本」或「死记硬背」即为反向理解——泛化恰恰强调**未见过的新情境**。

2. **答案要点**：
   ① **MSE 定义式**（003 P1）：

   $$
   MSE = \frac{1}{n} \sum (\hat{y} - y)^2
   $$

   ② **两个理由**——**消除正负号的影响**（让误差绝对值化，防止求和后正负误差互相抵消）；**放大误差便于优化**（误差 3 与 0.4 平方后变为 9 与 0.16，差异更明显）。
   ③ **训练流程五步**（003 P1）——**输入数据 → 计算预测 → 计算损失 → 计算梯度 → 更新参数**。每完成一轮循环参数就更接近一点，多轮迭代后模型逐渐收敛到最优解。
   **评分提示与易错提醒**：五步的顺序不可颠倒（先预测、再算损失、再算梯度、最后更新参数）；「求平均」这个 $n$ 常被漏写，写成 $\sum$ 不扣分但写全更稳妥；MSE 与第 2 章的「平方损失函数 $L(Y,f(X))=(Y-f(X))^2$」是同一思想在不同粒度上的表述，本题只要求写出课件的 MSE 形式。

### 参考答案与解析（第1章 B卷）

**一、单选题**

1. **答案：B**
   解析：直接代入课件的趋势线，$2.2 \times 100 + 10 = 230$（万元）（003 P1）。A 的 203 与 C 的 255 是数据集里 90 ㎡ 与 110 ㎡ 两行的真实价格，课件用它们给出「100 ㎡ 合理猜测应落在 203～255 万之间」的**区间直觉**；D 的 303 是 130 ㎡ 的真实价格。把「区间直觉」与「趋势线外推」混为一谈是本题最主要的坑。另外要注意：课件只是用「如果这条直线画得足够好」引出该式，并未把它说成最小二乘拟合结果，故不宜自行替换成其它直线方程。

2. **答案：B**
   解析：课件对「线性」的数学定义是两条**映射性质**——齐次性 $f(ax) = a \cdot f(x)$、可加性 $f(x+y) = f(x) + f(y)$，几何上在一维表现为直线、在高维表现为平面或超平面（003 P1）。A 正是课件点名要打破的直觉；C、D 均无依据——输入可以是多维的，含偏置项 $b$ 的直线也不过原点。**这是本章埋得最深的一个陷阱**：复习时若只记「线性 = 直线」，后面遇到「多项式回归算不算线性」就会全线崩溃。

3. **答案：A**
   解析：总得分 $= 50 + 30 + 30 = 110$ 分；课件的最终判定逻辑是「当所有特征加权后的总得分 **> 60 分**时，系统自动判定该邮件为垃圾邮件并拦截」（002 P14）。B 错在只累加了两类特征（把体积与时间当成同一项）；C 错在阈值记成 100 分；D 错在两处——得分应是 110 而非 60，且阈值判定是「**超过** 60 分」而不是「大于等于」，60 分本身落在阈值内。计算这类题务必先算术、再比阈值，两步分开写。

4. **答案：A**
   解析：课件对二者的区分是——**算法 =「学习的方法」**，指解决问题或执行计算的一套明确逻辑步骤，指导计算机如何观测数据、提取特征并找出规律；**模型 =「学习的结果」**，指算法学习海量数据后自主总结出的规则与参数集合（002 P10）。随机梯度下降描述的是「怎么学」，属于算法；模型则是学完之后的那组参数。C、D 是另外两个层次的词汇，与本题的辨析无关。**易错点**：算法与模型不可互换——说「梯度下降法是一个模型」即为错答。

5. **答案：A**
   解析：课件给出的向量简写是 $\hat{y} = \boldsymbol{w}^{\top} \boldsymbol{x} + b$，其中 $\boldsymbol{x} = [x_1, x_2, \cdots, x_d]^{\top}$、$\boldsymbol{w} = [w_1, w_2, \cdots, w_d]^{\top}$（003 P1）。B 漏掉了转置，内积必须是一行乘一列才能得到标量；C 把偏置错误地乘了进去（$b$ 是直接相加，不是相乘）；D 完全没有内积，把「加权求和」退化成了「向量相加」。本题的价值在于：这一行式子是后续神经网络「权重矩阵」的记号雏形，转置符写错，后面所有深度学习公式都会跟着歪。

**二、多选题**

1. **答案：DBC**
   解析：课件把线性回归的延伸分为两支（003 P1）：一支是**多项式回归**（当直线不够用时，$\hat{y} = w_1 x + w_2 x^2 + \cdots + w_d x^d + b$，$d=2$ 时拟合抛物线、阶数越高越灵活）；另一支是**逻辑回归与深度学习**（逻辑回归 = 线性回归 + 激活函数，$P(y=1 \mid x) = \sigma(wx+b) = \frac{1}{1+e^{-(wx+b)}}$，用于分类并输出概率；深度学习 = 多层逻辑回归的叠加，逐层「线性+激活」构成隐藏层）。A 与课件的图示直接矛盾：课件画的是 `输入 → 隐藏层₁ → 隐藏层₂ → … → 输出` 的**逐层堆叠**，不是并联投票，也不存在「没有隐藏层」的说法。

2. **答案：DB**
   解析：课件的核心定义是「机器学习是人工智能的核心分支，研究如何让计算机在**无需显式编程**的情况下，通过对海量数据的分析**自动学习规律**，并利用这些规律对未知场景进行**预测与决策**」（002 P3）。D、B 正是这两个关键限定；第三个限定「用于未知场景的预测与决策」也否定了 A。C 与「无需显式编程」「非人工编写固定规则」正面冲突，属于规则驱动（符号主义）的做法。**易错提醒**：答题时若只写「机器学习就是让机器学习」，既没有「无需显式编程」，也没有「数据」，属于最常见的失分点。

3. **答案：ABC**
   解析：A、B、C 与课件一致：$b$ 是面积为 0 时的理论基准值；$\boldsymbol{x}$ 是 $d$ 维特征列向量；$\boldsymbol{w}^{\top}\boldsymbol{x}$ 就是把各特征与对应权重逐项相乘再求和（即展开式 $w_1x_1 + \cdots + w_dx_d$ 的紧凑写法）。D 错在权重符号：距地铁越远房价越低，课件给出的权重方向是负的。D 考的正是 A 卷多选第 3 题的同一个易错点——**权重符号必须与直觉方向一致**，这是多特征线性回归里最容易凭空翻转的一项。

**三、简答题**

1. **答案要点**：
   ① **「线性 ≠ 直线」的两条性质**（003 P1）——**齐次性**：$f(ax) = a \cdot f(x)$；**可加性**：$f(x+y) = f(x) + f(y)$。这是对**映射性质**的定义：几何上一维时表现为直线，高维时表现为平面或超平面。
   ② **向量简化表达**（003 P1）：

   $$
   \hat{y} = \boldsymbol{w}^{\top} \boldsymbol{x} + b, \quad \boldsymbol{x} = [x_1, x_2, \cdots, x_d]^{\top}, \quad \boldsymbol{w} = [w_1, w_2, \cdots, w_d]^{\top}
   $$

   ③ **各符号含义**——$\hat{y}$：模型的预测值（如预测房价）；$\boldsymbol{x}$：由 $d$ 个特征组成的输入列向量（面积、楼层、距地铁、房龄……）；$\boldsymbol{w}$：与每个特征一一对应的权重向量；$b$：偏置（截距），面积为 0 时的理论基准值。
   **评分提示与易错提醒**：只答「线性就是一条直线」不得分——课件特意点出这是错的；漏掉 $\top$（转置）要扣分，因为内积必须「行乘列」才得到标量；本题的延伸价值在于：$\hat{y} = \boldsymbol{w}^{\top}\boldsymbol{x} + b$ 正是神经网络「权重矩阵」的记号雏形，后面复习逻辑回归与深度学习时会直接复用。

2. **答案要点**：
   ① **模型 1.0（概率盲猜）**（002 P11）——**信息**：只看历史频率。最近 10 封邮件中 6 封垃圾、4 封正常，得出垃圾邮件概率 60%，直接判定为垃圾邮件。**暴露的缺陷**：完全没有使用邮件本身的任何特征，60% 的准确率来自先验统计，一旦比例变化即失效。
   ② **模型 2.0（寻找单一特征规律）**（002 P12）——**新增信息**：发送时间。判定规则为「工作日发送 = 正常邮件，周末发送 = 垃圾邮件」。**解决的问题**：从「纯猜」变成「有依据地猜」，利用了办公节奏这一相关性。**暴露的缺陷**：仅靠「时间」一个特征过于绝对，会把朋友周末发来的 3KB 徒步通知误杀。
   ③ **模型 3.0（多维特征组合）**（002 P13）——**新增信息**：文件大小（正常邮件 1~7KB / 3KB，垃圾邮件 16KB+ / 20~35KB）。**判定规则**：「周末发送」+「文件大小 > 10KB」两个条件**同时满足**才判定为垃圾邮件（缺一不可）。**效果**：精准拦截周末群发的大附件营销邮件，同时避免误伤好友周末的 3KB 通知，鲁棒性明显提升。
   **评分提示与易错提醒**：三步的演进主线是「单一特征 → 多维特征组合」，答题时不能把模型 2.0 当成最终答案；若能补一句「多特征组合 + 逻辑与（缺一不可）带来鲁棒性」，属于加分项。

**三、简答题**

1. **答案要点**：
   ① **观察依据**（00 P6；01 P77）——课件给出的「数据大小—准确率」图显示：**各种不同算法在输入的数据量达到一定级数后，都有相近的高准确度**。
   ② **名言原句**——**「成功的机器学习应用不是拥有最好的算法，而是拥有最多的数据！」**
   ③ **实践启示**——① 在算法差距不大的情形下，**优先投入数据规模与质量**的收益高于盲目换算法；② 既然不同算法在数据量足够时准确率相近，说明**数据的量与质量是主要的竞争壁垒**；③ 该结论是相对的、针对「数据量达到一定级数」这一前提，不能反过来推出「算法不重要」或「任何算法都一样」。
   **评分提示与易错提醒**：名言必须原句写出才能得满分分；只答「数据很重要」而无观察依据，最多得一半分；把结论绝对化（「算法完全没用」）是常见的过度引申。

2. **答案要点**（01 P56）：
   ① **列表 (list)**——记号 `[ ]`，用来存储一连串元素的容器，**元素的类型可不相同**，且**元素的值可以修改**。
   ② **元组 (tuple)**——记号 `( )`，类似列表、元素同样进行索引计算，但**元素的值不能修改，只能读取**。
   ③ **集合 (set)**——记号 `set( )`，主要有两个功能：**进行集合操作**、**消除重复元素**；括号内可以是列表、字典或字符串（字符串以列表形式存储）。
   ④ **字典 (dict)**——记号 `{ }`，也叫关联数组（其他语言中称 map），使用**键-值 (key-value) 存储**，查找速度极快，**key 不能重复**。
   ⑤ **两类关键差异小结**——「**可修改 / 只读**」：list 可改、tuple 只读；「**按值位置 / 按键值**」：list、tuple 走索引位置，dict 走 key 查找。
   **评分提示与易错提醒**：只对比 list 与 tuple 最多得一半分，四种结构都要交代；「key 不能重复」与「dict 靠 key 查找」是两个独立得分点，容易漏写后者。

**三、简答题**

1. **答案要点**（01 P24、P25）：
   ① **经验风险的定义**——给定一个数据集，将**训练数据集的平均损失**称为经验风险；据此可写出全局损失函数：

   $$
   \underset{f}{\min}\; \frac{1}{N} \sum_{n=1}^{N} L(y_n, f(x_n))
   $$

   ② **为什么样本不足会过拟合**——样本数量足够大时，根据**大数定理**，经验风险近似于模型的期望风险，此时经验风险最小化能确保有好的学习性能；但当**样本数量不足**时，模型有充分自由度去「迁就」有限样本，单单利用经验风险最小化就可能把噪声也当成规律，即产生**过拟合**。
   ③ **结构风险最小化准则**——在经验风险上加上控制模型复杂度的**正则项 (Regularizer)**：

   $$
   \underset{f}{\min}\; \frac{1}{N} \sum_{n=1}^{N} L(y_n, f(x_n)) + \lambda J(f)
   $$

   ④ **两个符号的职责**——$J(f)$：对**模型复杂度**的惩罚，**模型越复杂 $J(f)$ 越大，模型越简单 $J(f)$ 越小**；$\lambda$：一个正的常数，叫**正则化系数**，用于**平衡经验风险和模型复杂度**。
   **评分提示与易错提醒**：$J(f)$ 的单调方向是本节最大的记反点（**越复杂越大**）；把 $\lambda$ 的作用说成「控制模型复杂度」而不提「平衡二者」，只能算半对；结构风险小的模型需要**经验风险与模型复杂度同时小**，因此对训练数据和测试数据都能有较好的拟合——这句话是理解正则化动机的关键，答到即为加分项。

2. **答案要点**（01 P59–P69、P65）：
   ① **五大模块定位**——**NumPy**：用 Python 实现的科学计算扩展程序库，提供强大的 N 维数组对象、成熟的广播函数库、整合 C/C++ 与 Fortran 的工具包，以及线性代数、傅里叶变换与随机数生成函数；**Pandas**：基于 NumPy 的工具，为解决数据分析任务而创建，核心结构是 Series 与 DataFrame；**SciPy**：构建在 NumPy 基础之上、专为科学与工程设计的工具包，含统计、优化、积分、线性代数、信号与图像处理等模块；**Matplotlib**：Python 的 **2D 绘图库**，可生成出版质量级别的图形（绘图框 → 子图 → 元素三层结构）；**Scikit-learn**：用于快速构建经典模型的机器学习库。
   ② **`.loc` 与 `.iloc` 的区别**——`df.loc[row_label, col_label]` 通过**标签**选取行 / 列；`df.iloc[row_loc, col_loc]` 通过**位置（自然数）**选取行 / 列。判别依据是：**参数是「名字」还是「第几个」**。另外 `df[5:10]` 是通过切片方式选取多行，`df[col_label]` 或 `df.col_label` 是选取列。
   **评分提示与易错提醒**：五个模块各占一分左右，只写 NumPy 与 Pandas 最多得一半分；`.loc` 用标签、`.iloc` 用位置不可记反，也不要把 `df[5:10]` 当成选列——它是切片选**多行**，选列要用 `df[col_label]`。

   解析：Z-Score 标准化后「处理后的数据均值为 0、方差为 1」（02 P20）。A 是归一化（最大-最小规范化）的结果，不是标准化的；B 把两者的结论凑到了一起——方差也变成了 1；D 混淆了两种方法：归一化映射到 $[0,1]$，标准化的结果不落在固定区间上。**易踩的坑**：用「[0,1]」去判断标准化、用「均值0方差1」去判断归一化。

4. **答案：A**
   解析：课件对过拟合的定义性描述是「过于强调拟合原始数据，而丢失了算法的本质：预测新数据」——虽然能非常好地适应训练集，但在新输入变量上预测时可能效果不好（02 P23）。B 是欠拟合；C 是特征尺度悬殊、需要归一化/标准化的问题；D 是学习率设置不当导致的优化问题。**易踩的坑**：把「训练集表现」当成判断依据。欠拟合与过拟合在测试集上都可能变差，区别在于**训练集上欠拟合也差、过拟合很好**。

5. **答案：D**
   解析：课件把 RMSE 定义为 $\sqrt{\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}}$，而 MSE 是 $\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}$，所以 $RMSE=\sqrt{MSE}$（02 P30）。B、A 都是编造的关系；C 也不对——MSE 大于 1 时 $\sqrt{MSE}<MSE$，MSE 小于 1 时反而 $\sqrt{MSE}>MSE$，不能一概而论。**易踩的坑**：忽视 RMSE 的唯一价值是**量纲**——RMSE 与 $y$ 同单位，能直接说「平均差了多少元」，MSE 是平方单位。

**二、多选题**

1. **答案：ACD**
   解析：最小二乘法的闭式解 $w=\left(X^{T}X\right)^{-1}X^{T}Y$ **一次计算直接得到**最优 $w$，不需要学习率、不需要迭代（A、C、D），但必须真的去算矩阵逆 $\left(X^{T}X\right)^{-1}$（D）。B 错在把梯度下降的「多次迭代」套到了最小二乘法上——这正是两者的核心差别之一。**易踩的坑**：误以为最小二乘法也是迭代算法，因而非要给它设一个学习率；课件明确指出矩阵逆的时间复杂度为 $O(n^3)$，一般 $n<10000$ 时才可接受（02 P18）。

2. **答案：ABC**
   解析：A、B、C 都与课件定义一致（02 P13–P17）。D 错在三处页面都反复标注了「同步更新 $w_j$（$j=0,1,\ldots,n$）」：所有 $w_j$ 都必须用**更新前**的同一组数据算出梯度，再一起更新，不能边算边改。**易踩的坑**：写代码或推公式时把 $w_j$ 的更新放在一个循环里边算边赋，导致实际梯度与公式不一致。

3. **答案：ABC**
   解析：课件明确区分了两者——归一化 $x^{*}=\frac{x-x_{min}}{x_{max}-x_{min}}$ 映射到 $[0,1]$，且**会改变**特征数据分布（A、B）；Z-Score 标准化 $x^{*}=\frac{x-\mu}{\sigma}$ 使均值为 0、方差为 1，其目的是让不同特征具备可比性，分布**没有发生改变**（C）。D 与课件原文相反。**易踩的坑**：只记结论不记目的。目的不同——归一化是让各特征对目标变量的影响一致，标准化是让不同特征之间具备可比性。

**三、简答题**

1. **答案要点**：
   ① 模型式：$h(x)=w_0+w_1x_1+w_2x_2+\cdots+w_nx_n$（02 P7）；令 $x_0=1$ 后可写成 $h(x)=w_0x_0+w_1x_1+\cdots+w_nx_n=w^{T}x$。
   ② 代价函数（平方和损失）：$J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}$（02 P8）；对应单样本损失函数 $l(x^{(i)})=\frac{1}{2}\left(h(x^{(i)})-y^{(i)}\right)^{2}$。
   ③ 融入 $w_0$：若表达式写成 $h(x)=w_0+w_1x_1+\cdots+w_nx_n+b$，则 $b$ 可以融入到 $w_0$，这样模型才能写成纯线性组合的向量内积形式。
   ④ 第 1 列全为 1：$X$ 是 $m$ 行 **$n+1$** 列，第 1 列不是原始特征，而是为了承载 $w_0$ 而人为加入的 $x_0=1$；因此 $w$ 是 $n+1$ 维，才能让 $Xw$ 与 $Y$ 维度一致（02 P9）。
   评分要点：模型式与代价函数各 2 分；$b$ 融入 $w_0$ 与 $x_0=1$ 的关系 2 分；第 1 列的含义及 $n+1$ 维 3 分。**注意**：课件把单样本向量形式写作 $w^{T}X$、整体矩阵形式写作 $Xw$，两种记号并存（课件此处存疑）；答题时写「单样本 $w^{T}x$，整体 $Xw$」即可。

2. **答案要点**（02 P30、P31）：

$$
MSE=\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}
$$

$$
RMSE(y,\hat{y})=\sqrt{\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}}
$$

$$
MAE(y,\hat{y})=\frac{1}{m}\sum_{i=1}^{m}\left|y^{(i)}-\hat{y}^{(i)}\right|
$$

$$
R^{2}(y,\hat{y})=1-\frac{\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}}{\sum_{i=1}^{m}\left(y^{(i)}-\overline{y}\right)^{2}}=\frac{SSR}{SST}=1-\frac{SSE}{SST}
$$

   课件还给出等价写法 $R^{2}=1-\frac{MSE}{Var}$。
   取值方向：**MSE、RMSE、MAE 都是越小越好**；**$R^2$ 越接近于 1 说明模型拟合得越好**（不是越接近 0 越好）。
   评分要点：四个公式各 1.5 分（共 6 分），取值方向 3 分。**易踩的坑**：① $R^2$ 与 $MSE$ 方向相反——$R^2$ 越大越好而 $MSE$ 越小越好，根源就在 $R^2=1-\frac{MSE}{Var}$；② 三个误差指标都要**除以 $m$**，而 P8 的代价函数 $J(w)=\frac{1}{2}\sum(\cdot)^2$ 是平方和、**不除 $m$**，两者只差一个常数倍 $\frac{1}{2m}$，不要在同一个式子里混用。

**一、单选题**

1. **答案：A**
   解析：$w_j:=1.5-0.1\times(4-2)\times3=1.5-0.6=0.9$。B 错在把误差项写成 $y^{(i)}-h(x^{(i)})=-(4-2)$，或把减号误写成加号，方向完全相反；C 错在漏乘了特征 $x_j^{(i)}$，得 $1.5-0.1\times2=1.3$；D 错在漏掉了学习率 $\alpha$，得 $1.5-2\times3=-4.5$。**易踩的坑**：① 更新式中是**减号**（沿负梯度方向才使代价函数下降），写成加号是最常见的错误；② 这里的 $w_j$ 是与所有 $w_j$（$j=0,1,\ldots,n$）**同步更新**的，更新时 $h(x^{(i)})$ 用的是更新前的那组 $w$。

2. **答案：B**

3. **答案：A**
   解析：课件演讲者备注原文是「从计算机求解梯度的复杂度来说，MSE 要优于 MAE，而且梯度也是动态变化的，能较快准确达到收敛」（02 P30）。B 理由讲反了——绝对值函数在 0 处不可导，这正是 MAE 求导不如 MSE 干净的原因；C 否定了课件结论；D 把「动态梯度」这项优势安到了 MAE 头上。

4. **答案：C**

5. **答案：A**

**二、多选题**

1. **答案：ABD**

**三、简答题**

1. **答案要点**：
   ① 四步链条（02 P9–P10）：

$$
J(w)=\frac{1}{2}(Xw-Y)^{T}(Xw-Y)
\ \longrightarrow\ \frac{\partial J(w)}{\partial w}=X^{T}Xw-X^{T}Y
\ \longrightarrow\ X^{T}Xw=X^{T}Y
\ \longrightarrow\ w=(X^{T}X)^{-1}X^{T}Y
$$

   ② 五角度对比（02 P18）：

   | 比较项 | 梯度下降 | 最小二乘法 |
   |---|---|---|
   | 是否需要选择学习率 $\alpha$ | 需要 | 不需要 |
   | 迭代次数 | 需要多次迭代 | 一次计算得出 |
   | 需要计算的中间量 | 梯度 | 矩阵逆 $\left(X^{T}X\right)^{-1}$ |
   | 特征数量 $n$ 大时 | 也能较好适用 | 运算代价大（$O(n^{3})$，一般 $n<10000$ 可接受） |
   | 适用范围 | 适用于各种类型的模型 | 只适用于线性模型，不适合逻辑回归等其他模型 |

   评分要点：推导链条 4 分（每行 1 分），五角度对比 5 分（每角度 1 分）。**易踩的坑**：① 展开平方项后 $w^{T}X^{T}Y$ 与 $Y^{T}Xw$ 互为转置、要合并成 $-2w^{T}X^{T}Y$，漏掉系数 2 会导致最后结果差一倍；② 课件 P10 上这四条公式的排版顺序是乱的（先出现结果式再出现推导式），考试按上面的合理顺序写即可（课件此处存疑）。

2. **答案要点**：
   ① 两个角度的取舍（02 P30 演讲者备注）：
   - **求解梯度的复杂度**：应该用 **MSE**——MSE 优于 MAE，而且梯度也是动态变化的，能较快准确达到收敛；
   - **离群点的性质**：若离群点是**实际数据或重要数据、且是应该被检测到的异常值**，用 **MSE**；若离群点仅代表**数据损坏或错误采样、无须给予过多关注**，用 **MAE**。

### 参考答案与解析（第4章 A卷）

**一、单选题**

1. **答案：A**
   解析：课件定义 $\sigma(z)=g(z)=\frac{1}{1+e^{-z}}$，为 S 形函数（Sigmoid function）（03 P8）。B 指数符号错，$\frac{1}{1+e^{z}}$ 在 $z\to+\infty$ 时趋于 0，是一条**递减**曲线，形状与判决规则都对不上；C 把 $z$ 放到了分子上，$z\to-\infty$ 时会发散成负数，根本不是概率；D 是另一种函数，取值可以为负。
   **易踩的坑**：$\sigma(z)=g(z)$ 两个记号在课件中完全等价，答题时任写其一即可。

2. **答案：C**
   解析：课件判决规则是「当 $\sigma(z)$ 大于等于 0.5 时预测 $y=1$，小于 0.5 时预测 $y=0$」（03 P8），0.8 显然满足前者。A 用 1 而不是 0.5 当阈值；B 与判决规则无关——判决只看 $\sigma(z)$ 不看 $z$ 的符号（虽然二者同向，但规则不是这么写的）；D 错在 $\sigma(z)$ 已经把 $z$ 的信息完全包含了，不需要额外知道 $z$。
   **易踩的坑**：$z$ 与 $h(x)=\sigma(z)$ 是两个不同的量——$z$ 是**线性部分**，可以取任意实数；判决用的是过了 Sigmoid 的概率值。

3. **答案：D**
   解析：课件做法是「先定义其中一类为类型 1（正类），其余数据为负类（rest）；接下来**去掉类型 1 数据**，剩余部分再次进行二分类……如果有 $n$ 类，那就需要分类 $n-1$ 次」（03 P6）。5 类即 $n-1=4$ 次，最后剩下的那一类充当了「rest」。A 错在多算了一个；C 错在一锅端；B 错在把「逐轮二分类」误当成两两配对。
   **易踩的坑**：$n$ 类需要训练 $n-1$ 个二分类器，**不是 $n$ 个，也不是 1 个**；课件该页只画了「① → ② → ③ → ……」的步骤示意、没有给具体 $n$ 的例子（课件此处存疑）。

4. **答案：A**
   解析：课件给出的损失函数为 $L\left(y,h(x)\right)=-y\log\left(h(x)\right)-\left(1-y\right)\log\left(1-h(x)\right)$，其中 $h(x)$ 表示预测值、$y$ 表示真实值（03 P13）。B 是第 3 章的平方和损失，D 是 MAE，二者都不是本章的代价口径；C 漏掉了最关键的负号——那样求的是对数似然，要**最大化**而不是最小化。
   ⚠️易错点：**课件该式在 Word 转 LaTeX 时，两处预测值都被误写成 `\hat{y}`**，导致公式中 $y$ 同时代表真实值和预测值；阅读与答题时一律按 $L\left(y,h(x)\right)$ 理解（课件此处存疑）。

5. **答案：C**
   解析：课件第三步给出 $J(w)=-\frac{1}{m}l(w)$，即在取对数得到的对数似然前加一个负号、并除以样本数 $m$（03 P14）。A 漏了负号，会把「最小化」变成「最大化」；B 是毫无依据的指数变换；D 是把求平均写成了求累加。
   **易踩的坑**：**「似然 → 取对数 → 加负号」三个动作符号不能错**；对数似然 $l(w)$ 要最大化，代价函数 $J(w)$ 要最小化，所以差一个负号。且 $l(w)$ 中两项之间是**加号**，取负号展开后才变成 $L\left(y,h(x)\right)$ 形式的**减号**——不要在 $l(w)$ 里直接写减号。

**二、多选题**

1. **答案：ABC**
   解析：A、B、C 均与课件一致（03 P8、P10）：$\sigma(z)$ 与 $g(z)$ 等价；求导得 $g'(z)=\frac{e^{-z}}{(1+e^{-z})^{2}}=\frac{1}{1+e^{-z}}\left(1-\frac{1}{1+e^{-z}}\right)=g(z)\left(1-g(z)\right)$；因 $g(z)\in(0,1)$，故 $g'(z)\leqslant\frac{1}{4}$。D 把导数与 $1-g(z)$ 混为一谈——$1-g(z)=\frac{e^{-z}}{1+e^{-z}}$ 并不是导数。

2. **答案：DBC**
   解析：D、B、C 直接来自课件的二分类模型假设与合并式（03 P12）。A 把**连乘**写成了连加——当 $y=1$ 时正确结果应为 $\left(h(x)\right)^{1}\cdot\left(1-h(x)\right)^{0}=h(x)$，而按 A 式会得到 $h(x)+1$，概率大于 1。
   📖必背：$\left(h(x)\right)^{y}\left(1-h(x)\right)^{1-y}$ 的巧妙之处——**$y=1$ 时第二项指数为 0 自动消失，$y=0$ 时第一项指数为 0 自动消失**，所以同一个式子同时表达了两种情形。

3. **答案：ABD**

**三、简答题**

1. **答案要点**（03 P9）：
   ① 事件的发生比 odds 是**事件发生与事件不发生的概率之比**：$\frac{p}{1-p}$，其中 $p$ 为随机事件发生的概率，$p$ 的范围为 $[0,1]$；
   ② 取对数并令它等于线性输出：$log\frac{p}{1-p}=w^{T}x=z$；
   ③ 求解 $p$：$p=\frac{1}{1+e^{-w^{T}x}}=\frac{1}{1+e^{-z}}$；
   ④ 于是模型假设为 $z=w^{T}x+b$，$h(x)=\sigma(z)=\sigma(w^{T}x)$，即把 $\log\frac{p}{1-p}$ 直接赋成 $w^{T}x$。

   ⚠️易错点：$p$ 的范围是 $[0,1]$，而 $z=w^{T}x$ 的范围是 $(-\infty,+\infty)$——**两者不是同一个东西**，$p=\sigma(z)$ 才是从后者到前者的映射。引入 Sigmoid 的理由也在这里：线性回归的 $h(x)=z=w^{T}x$ 范围是 $(-\infty,+\infty)$，而分类预测结果需要得到 $[0,1]$ 的概率值。

2. **答案要点**（03 P12、P13）：
   ① 假设函数：$h(x)=g\left(w^{T}x\right)=g(z)$，$z=w^{T}x$；若写 $h(x)=z=w_0+w_1x_1+\cdots+w_nx_n+b=w^{T}x+b$，则 $b$ 可以融入到 $w_0$，即 $z=w^{T}x$。
   ② 损失函数：$L\left(y,h(x)\right)=-y\log\left(h(x)\right)-\left(1-y\right)\log\left(1-h(x)\right)$。
   ③ 代价函数：

$$
J(w)=-\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}\log\left(h(x^{(i)})\right)+\left(1-y^{(i)}\right)\log\left(1-h(x^{(i)})\right)\right)
$$

   ④ 巧妙之处：该式是二分类模型假设 $p(y=1\mid x;w)=h(x)$、$p(y=0\mid x;w)=1-h(x)$ 合并后的写法——$y=1$ 时 $\left(1-h(x)\right)^{0}=1$ 自动消失，$y=0$ 时 $\left(h(x)\right)^{0}=1$ 自动消失，**同一个式子同时表达了两种情形**，不必分情况写两条式子。
   评分要点：三个公式各 2 分，巧妙之处的解释 3 分。
   ⚠️易错点：课件 P13 的损失函数在 Word 转 LaTeX 时两处预测值都被误写成 `\hat{y}`（课件此处存疑），答题一律写成 $h(x)$；另外这个 $J(w)$ 就是**交叉熵代价函数（对数损失）**，与第 3 章的平方和损失相对照记忆——P22 把负号放在求和号前、P23 把负号分配到每一项内部，两种写法不等价之外的差异只是记法，含义相同。

**三、简答题**

1. **答案要点**（03 P15–P17）：
   代价函数 $J(w)=-\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}\log\left(h(x^{(i)})\right)+\left(1-y^{(i)}\right)\log\left(1-h(x^{(i)})\right)\right)$。
   **第一步**（把 $h(x^{(i)})$ 用 Sigmoid 表达式代入并化简）：

$$
y^{(i)}\log\left(\frac{1}{1+e^{-w^{T}x^{(i)}}}\right)+\left(1-y^{(i)}\right)\log\left(1-\frac{1}{1+e^{-w^{T}x^{(i)}}}\right)=-y^{(i)}\log\left(1+e^{-w^{T}x^{(i)}}\right)-\left(1-y^{(i)}\right)\log\left(1+e^{w^{T}x^{(i)}}\right)
$$

   **第二步**（代入代价函数并对 $w_j$ 求导）：

$$
\frac{\partial}{\partial w_j}J(w)=-\frac{1}{m}\sum_{i=1}^{m}\left(-y^{(i)}\frac{-x_j^{(i)}e^{-w^{T}x^{(i)}}}{1+e^{-w^{T}x^{(i)}}}-(1-y^{(i)})\frac{x_j^{(i)}e^{w^{T}x^{(i)}}}{1+e^{w^{T}x^{(i)}}}\right)
$$

   **第三步**（代入 $h(x^{(i)})=\frac{1}{1+e^{-w^{T}x^{(i)}}}$ 合并同类项）：

$$
=-\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-h(x^{(i)})\right)x_j^{(i)}=\frac{1}{m}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}
$$

   **Sigmoid 导数性质的角色**：第二步到第三步之所以能把指数分式塌缩成 $\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$，关键就是把每个指数分式认成 $g'(z)=g(z)\left(1-g(z)\right)$ 的形式；$g'(z)$ 就是 $\frac{e^{-z}}{(1+e^{-z})^{2}}$。这是该性质在逻辑回归中唯一的用途。
   评分要点：第一步化简 2 分、第二步求导式 3 分、第三步结果 2 分、Sigmoid 导数性质的作用 2 分。

2. **答案要点**：
   ① **为什么不能用最小二乘法**：课件明确给出（02 P18）最小二乘法「**只适用于线性模型，不适合逻辑回归模型等其他模型**」——逻辑回归虽然形式上是「线性模型 + Sigmoid」，但它的代价函数是交叉熵，$w=\left(X^{T}X\right)^{-1}X^{T}Y$ 这个闭式解是对平方和损失求导得来的，对交叉熵并不成立；而梯度下降「适用于各种类型的模型」，特征数量 $n$ 大时也能较好适用，所以逻辑回归只能用梯度下降求解。⚠️易错点：**逻辑回归不是最小二乘法的解**。
   ② 加入正则化后的代价函数（03 P18）：

$$
J(w)=\frac{1}{m}\sum_{i=1}^{m}\left[-y^{(i)}\log\left(h(x^{(i)})\right)-\left(1-y^{(i)}\right)\log\left(1-h(x^{(i)})\right)\right]+\frac{\lambda}{2m}\sum_{j=1}^{n}w_{j}^{2}
$$

   后一项为正则化项。
   ③ $\lambda$ 与拟合状态的关系（03 P18 三图对比）：**没有正则化 → 过拟合；正则化过度 → 欠拟合；适当的正则化 → 目标状态**；并且课件指出「**当 $\lambda$ 的值开始上升时，降低了方差**」。所以 $\lambda$ 不是越大越好，要调到「适当」为止。
   评分要点：① 原因 3 分（含「只适用于线性模型」这一依据 1 分）；② 公式 3 分（交叉熵部分 2 分、正则项 $\frac{\lambda}{2m}\sum w_j^2$ 1 分）；③ 三种状态对应 3 分。
   ⚠️易错点：课件三个正则化公式中的求和都是 $\sum_{j=1}^{n}$，即不含偏置项 $w_0$，课件未说明是有意约定还是笔误（**课件此处存疑，答题按课件口径写即可，不必争论**）。

   P(Y|X)=\frac{P(X,Y)}{P(X)}=\frac{P(X|Y)P(Y)}{P(X)}
   $$

   即**后验概率 =（似然度 × 先验概率）/ 边际似然度**（04 P6）。
   ② **辨析方向**：$P(X|Y)$ 是似然度，竖线右边是 $Y$（假设），含义是「在 $Y$ 成立的前提下观测到 $X$」；$P(Y|X)$ 是后验概率，竖线右边是 $X$（证据），含义是「在看到 $X$ 之后 $Y$ 成立的置信度」。**二者方向相反、不是同一件事**，这是本章最典型的符号陷阱。
   ③ **联合分布式**：生成模型由 $P(X|Y)$ 与 $P(Y)$ 合成 $P(X,Y)=P(X|Y)P(Y)=P(Y)P(X|Y)$（04 P6、P9）。
   ④ **归为生成方法的理由**：朴素贝叶斯先估计 $P(X|Y)$ 和 $P(Y)$，得到联合概率分布，再由它求后验并分类，属于「学联合分布再求后验」的路径；而线性回归、逻辑回归、决策树、支持向量机等是直接学习 $Y=f(X)$ 或直接估计 $P(Y|X)$ 的判别方法（04 P8）。

2. **答案要点**：
   ① **施加假设前（链式法则）**：每项都依赖前面的词：

   $$
   p(x^{(1)},\ldots,x^{(50000)}|y)=p(x^{(1)}|y)\,p(x^{(2)}|y,x^{(1)})\,p(x^{(3)}|y,x^{(1)},x^{(2)})\cdots
   $$

   ② **施加朴素贝叶斯假设后（各词只依赖 $y$）**：

   $$
   p(x^{(1)},\ldots,x^{(50000)}|y)=p(x^{(1)}|y)\,p(x^{(2)}|y)\cdots p(x^{(50000)}|y)=\prod_{i=1}^{m}p(x^{(i)}|y)
   $$

   ③ **收益**：连乘规模从**指数级降到线性级**，模型包含的条件概率数量大为减少，学习与预测大为简化，因而朴素贝叶斯**高效且易于实现**（04 P10）。
   ④ **代价**：由于这是一个较强的假设（现实中词语之间常共现、相互关联），朴素贝叶斯法的缺点是**分类的性能不一定很高**（04 P10）。
   ⑤ **补充（可加分）**：课件 04 P12 第三行连乘上限写作 $m$，而前两行按 50000 个单词展开，课件未说明 $m$ 与 50000 的关系（课件此处存疑，按「非词表词全展开、词表内逐词连乘」理解即可）。

**三、简答题**

1. **答案要点**：
   ① **第一步：用贝叶斯定理写出后验概率（04 P16，式(2)）**：

   $$
   P(Y=c_k|X=x)=\frac{P(X=x,Y=c_k)\,P(Y=c_k)}{\displaystyle\sum_{k=1}^{K}P(X=x,Y=c_k)\,P(Y=c_k)}
   $$

   即：已知输入 $x$，分别算每个候选类的「似然 × 先验」，再用全体求和归一化成真正的后验概率。
   ② **第二步：把条件独立假设式(1) 代入式(2) 的分子（04 P15、P17）**：

   $$
   P(X=x,Y=c_k)=\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)
   $$

   这一步把「难以估计的联合分布」拆成 $n$ 个「容易逐特征估计的条件概率」，是全章最关键的化简。
   ③ **第三步：约去分母，得分类器式（04 P17）**：

   $$
   y=f(x)=\arg\max_{c_k}\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)
   $$

   分母是对所有类求和的整体归一化项，与当前比较的类别无关，取 $\arg\max$ 时可以整体约去；因此**只需比较各类「先验 × 各特征条件概率连乘」的大小**。
   ④ **链条总结（可加分）**：贝叶斯公式给出式(2) → 条件独立假设把分子拆成连乘 → 分母与类别无关可约 → 三步叠加才得到分类器。只背最后一个式子而不理解来源，是本章最常见的复习失误。

2. **答案要点**：
   ① **零概率现象**：04 P22 中「close」未出现在任何 Sports 样本中，故 $P(close|Sports)=0$；若不平滑，连乘结果为 0，Sports 类被「同归于尽」，会把 “D very close game” 误判为 Not Sports。
   ② **平滑前的数值**：$P(close|Sports)=\frac{0}{11}=0$。
   ③ **平滑后的数值**（04 P23）：词表共 **14** 个不同单词，

   $$
   P(game|sports)=\frac{2+1}{11+14}
   $$

   同理 $P(close|Sports)=\frac{0+1}{11+14}=\frac{1}{25}$。即**分子加 1、分母加词表大小 14**，两个操作必须同时进行。
   ④ **三条性质（04 P24）**：避免了出现概率为 0 的情况；保证每个值都在 0 到 1 的范围内；保证最终和为 1 的概率性质。
   ⑤ **一般形式（可加分）**：$P_\lambda(C_k)=\frac{\sum_{i=1}^{N}I(y_i=C_k)+\lambda}{N+K\lambda}$，$P_\lambda(x_i=a_j|y=C_k)=\frac{\sum_{i=1}^{N}I(x_i=a_j,y_i=C_k)+\lambda}{\sum_{i=1}^{N}I(y_i=C_k)+D\lambda}$，其中 $I(\cdot)$ 为示性函数、$K$ 为类别数量、$D$ 为不同值数量、$\lambda$ 通常取 1。**易错点**：类别先验分母加 $K\lambda$，特征条件概率分母加 $D\lambda$，两者不可互换。

   解析：05 P12 的混淆矩阵以「实际值」为行、「预测值」为列：左上是 TP（实际正、预测正），右上角是 FN（实际正、预测负），左下角是 FP（实际负、预测正），右下角是 TN（实际负、预测负）。**易错点**：行是实际值、列是预测值，**看反行就会把 FP 当成 FN**，而 FP 与 FN 恰好是 Precision 与 Recall 各自的分母项，混淆后两个指标全错。

3. **答案：D**
   解析：05 P12 给出 $Precision=\frac{TP}{TP+FP}$、$Recall=\frac{TP}{TP+FN}$。Recall 的分母 $TP+FN$ 即「实际总正例数量」，含义是**实际为正**的样本数；Precision 的分母 $TP+FP$ 是「预测为正」的数量；Accuracy 的分母是全部样本；F1 是 Precision 与 Recall 的调和平均，不直接对应「正例数量」这一分母。**易错点**：Precision 与 Recall 分母含义不同，是本章最经典的易错点。

4. **答案：B**
   解析：05 P19 给出 Z-Score 标准化 $x^{*}=\frac{x-\mu}{\sigma}$，其中 $\sigma^{2}=\frac{1}{m}\sum_{i=1}^{m}(x^{(i)}-\mu)^{2}$、$\mu=\frac{1}{m}\sum_{i=1}^{m}x^{(i)}$，处理后数据**均值为 0、方差为 1**。A 描述的是归一化（最大-最小规范化）映射到 [0,1] 区间；C 错；D 错，标准化并不改变数据的分布形态为正态分布。

5. **答案：C**
   解析：05 P20 列出**不需要做**的模型：决策树、基于决策树的 Boosting 和 Bagging 等集成学习模型（树模型）以及**朴素贝叶斯**——它们对特征取值大小并不敏感。A、B、D 均属于**需要做**的一类：基于距离度量的模型（KNN、K-means）、感知机、SVM、神经网络，线性回归类模型一般也需要做。**易错点**：树模型与朴素贝叶斯不需要归一化/标准化，这是「一刀切全做归一化」的常见反例。

**三、简答题**

1. **答案要点**：
   ① **四个公式**（05 P12）：

   $$
   Accuracy=\frac{TP+TN}{TP+TN+FP+FN}
   $$

   $$
   Precision=\frac{TP}{TP+FP}\qquad Recall=\frac{TP}{TP+FN}\qquad F1=\frac{2\times Precision\times Recall}{Precision+Recall}
   $$

   ② **分母含义**（这是本题的采分重点）：
   - Accuracy 分母 = $TP+TN+FP+FN$，即**全部样本**；
   - Precision 分母 = $TP+FP$，即**「预测为正」的数量**（识别出的正例）；
   - Recall 分母 = $TP+FN$，即**「实际为正」的数量**（实际总正例数）；
   - F1 无独立的样本分母，是 Precision 与 Recall 的调和平均，因此二者**必须同时看**，任何一项偏低都会拉低 F1。
   ③ **四个符号**（配套记忆）：TP 预测为真实际为真、TN 预测为假实际为假、FP 预测为真实际为假（错误肯定）、FN 预测为假实际为真（错误否定）。
   ④ **补充示例（可加分）**：猫狗算例 100 张（猫 60、狗 40）中 $TP=40$、$FN=20$、$FP=10$、$TN=30$，则 $Accuracy=70/100=0.7$、$Precision=40/50=0.8$、$Recall=40/60\approx0.67$；注意本例 Precision 的分母 50 恰好等于负例数纯属巧合，不要当成规律。

2. **答案要点**：
   ① **归一化（最大-最小规范化）**（05 P19）：

   $$
   x^{*}=\frac{x-x_{min}}{x_{max}-x_{min}}
   $$

   处理后数据被映射到 **[0,1] 区间**。
   ② **Z-Score 标准化**（05 P19）：

   $$
   x^{*}=\frac{x-\mu}{\sigma},\qquad \sigma^{2}=\frac{1}{m}\sum_{i=1}^{m}\left(x^{(i)}-\mu\right)^{2},\qquad \mu=\frac{1}{m}\sum_{i=1}^{m}x^{(i)}
   $$

   处理后数据**均值为 0、方差为 1**。
   ③ **目的与适用条件**：归一化的目的是使各特征对目标变量的影响一致；标准化的目的是让不同特征之间具备可比性，**当数据特征取值范围或单位差异较大时，最好做一下标准化处理**。
   ④ **为什么值得做**（05 P17、P19 演讲者备注）：一是提升模型精度，二是加速模型收敛——若一个特征取值范围是 5000~10000、另一个只有 0.1~1，无论什么模型第一个特征对结果的影响都会大于第二个，这样的模型很难有效做出准确预测；标准化后寻优过程明显变平缓，更容易正确收敛到最优解。
   ⚠️**课件存疑提示**：关于「归一化会改变分布、标准化不改变分布」的表述，05 P19 正文与演讲者备注均如此表述，但课件未加条件说明（本章存疑点第 1 条），答题按课件原文表述即可。

**三、简答题**

1. **答案要点**：
   ① **期望泛化误差的分解式**（05 P32）：

   $$
   E(f;A)=bias^{2}(x)+var(x)+\varepsilon^{2}
   $$

   ② **学习算法的期望预测**（05 P32）：

   $$
   \overline{f}(x)=E_A\left[f(x;A)\right]
   $$

   ③ **三项定义式**：

   $$
   bias^{2}(x)=\left(\overline{f}(x)-y\right)^{2}
   $$

   $$
   var(x)=E_A\left[\left(f(x;A)-\overline{f}(x)\right)^{2}\right]
   $$

   $$
   \varepsilon^{2}=E_A\left[\left(y_A-y\right)^{2}\right]
   $$

   其中 $y$ 为 $x$ 在数据集中的标记、$y_A$ 为 $x$ 的真实标记、$f(x;A)$ 为训练集 $A$ 上学得模型 $f$ 在 $x$ 上的预测输出。
   ④ **推导中用到的关键假设**（05 P33、P34）：因为 $\overline{f}(x)$ 和 $y$ 均为常量，且**噪声期望为零** $E_A[(y-y_A)]=0$，故交叉项 $2E_A[(\overline{f}(x)-y)(y-y_A)]=0$，分解才成立。
   ⑤ **两项式与三项式的关系（采分点）**：课件 05 P31 图注的「**总体误差 = 偏差² + 方差**」是上述三项分解在**忽略噪声项**时的简化形式；课件未明确说明二者关系（课件此处存疑），答题时按「两项式是三项式丢掉噪声后的写法」表述最稳妥。
   ⑥ **模型复杂度的含义（可加分）**：随模型复杂度增加，方差逐渐增大、偏差逐渐减小，总体误差呈 U 形；虚线处是模型复杂度的最恰当选择，其「偏差」和「方差」也都适度，才能「适度拟合」。

2. **答案要点**：
   ① **两条诊断规则**（05 P35）：

   $$
   \text{训练集误差} \approx \text{交叉验证集误差} \Longrightarrow \text{偏差 / 欠拟合（Underfitting）}
   $$

   $$
   \text{交叉验证集误差} \gg \text{训练集误差} \Longrightarrow \text{方差 / 过拟合（Overfitting）}
   $$

   ② **本题情形（远大于）**：结论为**高方差 / 过拟合**；处方三条（05 P36 第 1、2、6 条）：获得更多的训练实例；尝试减少特征的数量；尝试**增加**正则化程度 $\lambda$。

1. **答案要点**：

   ```python
   from sklearn.linear_model import LinearRegression
   lr = LinearRegression(normalize=True)   # 构建模型实例
   lr.fit(X_train, y_train)                # 训练模型
   y_pred = lr.predict(X_test)             # 作出预测
   ```

   ③ **转换器示例**（06 P11）：

   ```python
   from sklearn.preprocessing import StandardScaler
   scaler = StandardScaler()          # 构建转换器实例
   scaler.fit_transform(X_train)      # 拟合及转换
   ```

   ④ **方法上的差别**：两者都是 `fit` 开始；模型类用 `predict` 输出**预测类别标签或预测值**（分类器还可用 `predict_proba` 输出属于各类的**概率**，用于画 ROC/PR 曲线、调分类阈值、与其他模型比较）；转换器不预测，而是用 `transform` 输出**变换后的数据**，并且提供 `fit_transform` 一步完成拟合与转换。

   ③ **与第 6 章的对应**：验证集用于**模型选择/调超参数**（可选），测试集用于**最终评估**；sklearn 的做法正是把这两件事分开，避免用测试集反复调参造成的信息泄漏。
   ④ `stratify=y` 的作用（06 P10）：**分层策略**，使训练集与测试集中各类别数据的比例与原始数据集比例一致；在不平衡数据上，可避免少数类样本被集中或稀释到某一半，保证评估结果有代表性。

1. **答案要点**：
   ① **交叉验证代码**（06 P25）：

   ```python
   from sklearn.model_selection import cross_val_score
   clf = DecisionTreeClassifier(max_depth=5)
   scores = cross_val_score(clf, X_train, y_train, cv=5, scoring='f1_weighted')
   ```

   `cv=5` 表示**使用 5 折交叉验证**；`scoring='f1_weighted'` 指定**评分函数为 F1 值**；返回值 `scores` 是各折的评分。
   ② **网格搜索代码**（06 P26）：

   ```python
   from sklearn.model_selection import GridSearchCV
   from sklearn import svm
   svc = svm.SVC()
   params = {'kernel': ['linear', 'rbf'], 'C': [1, 10]}
   grid_search = GridSearchCV(svc, params, cv=5)
   grid_search.fit(X_train, y_train)
   grid_search.best_params_
   ```

   `best_params_` 是搜索得到的最优超参数组合；`cv=5` 表示用 5 折交叉验证为每组参数打分。
   ③ **三者分工**（跨章联动）：
   - `train_test_split`：只负责**数据划分**——按 `test_size=0.3` 切出 70% 训练集与 30% 测试集；注意它只有两半。
   - `cross_val_score`：负责**模型评估**——在训练集内部做 $k$ 折交叉验证，给出模型在「未见过数据」上的平均表现，承担了第 6 章**验证集**的角色。
   - `GridSearchCV`：负责**调参/模型选择**——在参数网格上穷举、每组参数用 `cv` 交叉验证打分，取 `best_params_`；它是「选模型」的自动化实现。
   ④ **总原则**：先用 `train_test_split` 把**测试集隔离**，所有评估与调参都只在训练集内部进行，测试集只在最后用一次；否则就会用测试集反复调参造成信息泄漏。
   ⑤ **补充（可加分）**：若超参数较多，可用 `RandomizedSearchCV` 在参数子空间中随机采样（06 P27），时间耗费较少、更容易找到局部最优。
   ⚠️**课件存疑提示**：06 P27 正文称随机搜索「选取空间中的 **100 个点**」，而同页代码写的是 `n_iter=10`，两处数值不一致、课件未说明（本章存疑点第 3 条）。答题时按「随机采样若干点」表述最稳妥。
