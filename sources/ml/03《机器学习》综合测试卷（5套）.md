### 参考答案与解析（第1套）

**一、单选题**

1. **答案：B**
   解析：课件给出「智能 = 学习能力 + 迁移能力」——学习能力是认知的基石，从海量数据中提炼规律；迁移能力是进化的翅膀，将经验灵活应用于全新未知场景、举一反三。A 项「数据 + 算力」是 AI 爆发的两块基石，不是智能的本质公式；C 项混淆了算法与模型；D 项是早期规则驱动（符号主义）路线的做法，恰恰是课件认为走不通的那条路。（001 P4、P15）

2. **答案：A**
   解析：算法＝「学习的方法」，是解决问题或执行计算的一套明确逻辑步骤，指导计算机如何观测数据、提取特征并找出规律；模型＝「学习的结果」，是学习后自主总结出的规则与参数集合。故算法是构建模型的「设计师」，负责规划学习路径，模型是算法的产出物。B、C 把两者关系颠倒；D 与课件结论相反——数据与算力是 AI 爆发的两块基石，与算法/模型不构成对应关系。（002 P10）

3. **答案：B**
   解析：模式识别源自工业界，机器学习来自计算机学科，Bishop 在《Pattern Recognition And Machine Learning》开篇指出「它们中的活动可以被视为同一个领域的两个方面」。A 项是「数据挖掘 = 机器学习 + 数据库」；D 项是「计算机视觉 = 图像处理 + 机器学习」；C 与课件的层次划分（AI ⊃ ML ⊃ DL）矛盾。（01 P10）

4. **答案：C**
   解析：现有优化方法主要有梯度下降法、牛顿法、拟牛顿法、ADAM 等等；课件明确指出「本课程中，用梯度下降法作为主要的优化算法」。A、B、D 都是课件列出的方法，但不是本课程的主要优化算法。（01 P26）

5. **答案：D**
   解析：$J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}$，系数 $\frac{1}{2}$ 是为了便于计算，使对平方项求导后的常数系数为 1，这样形式上稍微简单一些。有些教科书把系数设为 $\frac{1}{2}$，有些设置为 1，这些都不影响结果（写成 1 时要除以 $2m$）。A 项的非负性由平方项本身保证；C、B 均非课件所述。（02 P8）

6. **答案：D**
   解析：$\sigma(z)=g(z)=\frac{1}{1+e^{-z}}$，其取值恒在 $(0,1)$ 内。决策规则：当 $\sigma(z)$ 大于等于 0.5 时预测 $y=1$，小于 0.5 时预测 $y=0$。A 项的阈值 1 不可能取到；C 项把 0.5 的阈值错加在 $z$ 上（$z$ 的范围是 $(-\infty,+\infty)$，不是概率）；B 项方向相反——$w^{T}x+b\le 0$ 对应 $\sigma(z)\le 0.5$，应预测 $y=0$。（03 P8）

7. **答案：C**
   解析：逻辑回归的模型假设为 $h(x)=g(w^{T}x)=g(z),\ z=w^{T}x$，其中 $g(z)=\frac{1}{1+e^{-z}}$。A 项 $h(x)=w^{T}x+b$ 是线性部分（即 $z$），不是概率；B 项指数符号取反；D 项的分式不是逻辑函数。注意课件中 $\sigma(z)=g(z)$ 两个记号完全等价，任写其一即可。（03 P8、P12）

8. **答案：D**
   解析：贝叶斯公式 $P(Y|X)=\frac{P(X,Y)}{P(X)}=\frac{P(X|Y)P(Y)}{P(X)}$ 中，$P(Y|X)$ 是后验概率、$P(X|Y)$ 是似然度、$P(Y)$ 是先验概率、$P(X)$ 是**边际似然度**——它是与类别无关的证据项。记忆口诀：后验概率 =（似然度 × 先验概率）/ 边际似然度。A、B、C 三项分别把三个位置搞错。（04 P6）

9. **答案：D**
   解析：$E(f;D)=bias^{2}(x)+var(x)+\varepsilon^{2}$，即泛化误差由偏差的平方、方差与噪声三部分构成。课件 05 P31 的图注另给出简化形式「总体误差 = 偏差² + 方差」（两项，不含噪声）。A 项漏掉噪声项；B 项漏掉偏差项；C 项把 $bias^{2}$ 写成 $bias$（线性偏差）——课件明确是偏差的平方。（05 P31、P32）

10. **答案：D**
   解析：网格搜索 `GridSearchCV` 在参数网格上进行穷举搜索，方法简单但是搜索速度慢（超参数较多时），且不容易找到参数空间中的局部最优。A 项是随机搜索 `RandomizedSearchCV` 的做法；C、B 均非超参数搜索的做法。（06 P26、P27）

**二、填空题**

1. **答案：** $\left(X^{T}X\right)^{-1}X^{T}Y$
   解析：由 $X^{T}Xw=X^{T}Y$ 两边左乘 $\left(X^{T}X\right)^{-1}$ 得到。这是最小二乘法的解——一次计算直接得到最优 $w$，不需要学习率，也不需要迭代。（02 P10）
2. **答案：** $g(z)\left(1-g(z)\right)$
   解析：$g'(z)=\frac{e^{-z}}{\left(1+e^{-z}\right)^{2}}=\frac{1}{1+e^{-z}}\left(1-\frac{1}{1+e^{-z}}\right)=g(z)\left(1-g(z)\right)$。因为 $g(z)\in(0,1)$，所以 $g'(z)\leqslant \frac{1}{4}$。（03 P10）
3. **答案：** 可能单词（词表）
   解析：拉普拉斯平滑的做法是为每个计数加 1（因此永远不会为零），同时把可能单词的数量添加到除数中（因此计算结果永远不会大于 1）。本案例中可能的单词（词表）共 14 个，所以分母是 $11+14$。（04 P23）
4. **答案：** FP（错误肯定，False Positive）
   解析：混淆矩阵的行是实际值、列是预测值。预测为正（Positive）而实际为负（Negative）落在第一行第二列，记作 FP。（05 P12）
5. **答案：** `fit`（训练／拟合）
   解析：统一 API 三段式是「构建模型／转换器实例（可传参数）→ `fit` 训练 → `predict`/`transform` 输出」。模型类换名字、方法名不变；转换器（如 `StandardScaler`）多一步 `fit_transform`，一次完成拟合与转换。（06 P11、P14）

**三、简答题**

1. **总起（2分）：** 机器学习的一般步骤就是人类「归纳—推测」过程的模拟。
   **分述①归纳与推测的对应（4分）：** 人类在成长、生活过程中积累了很多历史与经验，定期地对这些经验进行「归纳」，获得了生活的「规律」（如学历史——「历史往往不一样，但历史总是惊人的相似」）；遇到未知问题或需要对未来进行「推测」时，使用这些「规律」进行推测，从而指导自己的生活和工作。机器学习中的「训练」与「预测」过程，分别对应人类的「归纳」与「推测」过程。
   **分述②结论性质（4分）：** 由于机器学习不是基于编程形成的结果，因此它的处理过程**不是因果的逻辑，而是通过归纳思想得出的相关性结论**——不要把相关当因果。
   评分说明：只写「训练对应归纳、预测对应推测」而无「相关性而非因果」限定，最高给 6 分。（00 P3；01 P74）

2. **总起（1分）：** 从「模型式」到「闭式解」共四步。
   **分述①模型式（2分）：** 线性回归通过属性的线性组合进行预测，$h(x)=w_0+w_1x_1+w_2x_2+\cdots+w_nx_n$；设 $x_0=1$ 则可写成 $h(x)=w_0x_0+w_1x_1+\cdots+w_nx_n=w^{T}X$，即把常数项 $b$「吸收」进 $w_0$。
   **分述②代价函数（2分）：** $J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}$；对应单样本损失 $l(x^{(i)})=\frac{1}{2}\left(h(x^{(i)})-y^{(i)}\right)^{2}$。系数 $\frac{1}{2}$ 仅为求导方便，不影响结果。
   **分述③矩阵化与求导（3分）：** 写成 $J(w)=\frac{1}{2}(Xw-Y)^{2}=\frac{1}{2}(Xw-Y)^{T}(Xw-Y)$；利用 $\sum_i z_i^2=z^{T}z$ 展开得 $w^{T}X^{T}Xw-2w^{T}X^{T}Y+Y^{T}Y$；逐项套用求导法则 $\frac{\partial(X^{T}AX)}{\partial X}=(A+A^{T})X$（$A=X^{T}X$ 是对称阵，故为 $2X^{T}Xw$）、$\frac{\partial(X^{T}Y)}{\partial X}=Y^{T}$，$Y^{T}Y$ 与 $w$ 无关求导为 0，得 $\frac{\partial J(w)}{\partial w}=X^{T}Xw-X^{T}Y$。
   **分述④求闭式解（2分）：** 令偏导为 0 得 $X^{T}Xw=X^{T}Y$，两边左乘 $\left(X^{T}X\right)^{-1}$ 得 $\boxed{w=\left(X^{T}X\right)^{-1}X^{T}Y}$，一次计算直接得到最优 $w$，不需要学习率也不需要迭代。
   评分说明：只背闭式解而不写推导链条，本题最高给 3 分。（02 P7–P10）

3. **总起（2分）：** 朴素贝叶斯分类器的推导由「贝叶斯定理」与「条件独立假设」两个动作叠加而成。
   **分述①贝叶斯定理给出后验（3分）：** $P(Y=c_k|X=x)=\frac{P(X=x,Y=c_k)P(Y=c_k)}{\sum_{k=1}^{K}P(X=x,Y=c_k)P(Y=c_k)}$，将后验概率最大的类作为 $x$ 的类输出；后验概率最大等价于 0-1 损失函数时的期望风险最小化。
   **分述②施加条件独立假设（3分）：** 式(1) $P(X=x,Y=c_k)=\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)$，代入上式即把分子拆成连乘。形式化写法为 $P(X|Z)=P(X|Y,Z)$。
   **分述③分类器式与分母约去（2分）：** 分母是对所有类求和后得到的整体归一化项，与当前比较的类别无关，取 $\arg\max$ 时可整体约去，得 $y=f(x)=\arg\max_{c_k}\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)$。
   评分说明：须答出「朴素」= 假设特征之间条件独立（04 P11），这是一个**较强的假设**，它使模型包含的条件概率数量大为减少，学习与预测大为简化，因而高效且易于实现，缺点是分类性能不一定很高；不答此点扣 2 分。（04 P10、P11、P13、P15–P17）

4. **总起（2分）：** sklearn 中所有模型与转换器都遵循同一个调用模子。
   **分述①三段式（3分）：** 导入类 → 构建实例（可传参数）→ `fit` 训练 → `predict`/`transform` 输出。例如 `scaler = StandardScaler()` 后 `scaler.fit_transform(X_train)`；`lr = LinearRegression(normalize=True)` 后 `lr.fit(X_train, y_train)`、`lr.predict(X_test)`。模型类换名字、方法名不变；转换器多一步 `fit_transform`（一次完成拟合与转换）。掌握这条主线，本章全部 API 都能迁移使用。
   **分述②`predict` 与 `predict_proba` 的区别（3分）：** `predict(X_test)` 返回每个样本的**预测类别标签**（如 0/1），用于直接出结果；`predict_proba(X_test)` 返回每个样本属于各类的**概率**，用于画 ROC/PR 曲线、调分类阈值、与其他模型比较。
   **分述③易错提醒（2分）：** 只有支持输出概率的分类器才有 `predict_proba`；`y_pred` 是标签、`y_prob` 才是概率，绘图取阈值时用的是 `y_prob`。
   评分说明：三段式与两方法区别各占一半权重，缺一扣相应分数。（06 P11、P16）

**四、论述题**

1. **总起（3分）：** 泛化是从具体案例中抽取共性规律、把过往经验迁移到全新的未见过情境中做出正确判断的能力，课件称其为智能的「核心」；人类识别苹果的两步机制正是泛化在生物侧的对应物。

   **分述①智能的两个组成部分（3分）：** 智能 = 学习能力 + 迁移能力。学习能力是从海量数据中提炼规律、构建底层认知框架，是智能产生的源泉；迁移能力是将习得的经验灵活应用于全新未知场景、实现举一反三，是智能进阶的关键。人类被开水烫过一次后不仅避开那个杯子，还会警惕所有冒热气的物体——这正是迁移能力（泛化）的典型表现。

   **分述②人类认知的两步机制（4分）：** 第一步**提取特征**——剥离无关细节，精准捕捉核心属性，将碎片化的视觉信息转化为可复用的抽象特征；第二步**迁移学习**——基于已形成的认知框架，面对从未见过的新品种也能快速匹配特征、实现跨场景的识别与归类。人类从未死记硬背「标准答案」：红苹果、青苹果、抽象符号都能瞬间识别，却说不出直径、曲率的精确公式——这说明智能的核心不在「存储答案」而在「提取规律」。这一逻辑为现代深度学习奠定了基石。

   **分述③为什么必须用模型代替规则（5分）：** 早期 AI 走「规则驱动（符号主义）」的专家系统路线，工程师以「上帝视角」编写代码，核心困境是**规则写不完**——被咬一口、烂了一半或逆光下的苹果都需要重新编写规则，系统难以泛化。「学习驱动（联结主义）」路线放弃人工编写规则，让机器从海量数据中自主归纳特征，其成功关键是数据驱动与自主归纳。因此，机器学习用「在庞大参数空间中通过海量计算持续迭代」把人类不可行的探索规模化、可重复化：训练 AI 的本质是在高维参数空间中搜索出最能解释数据底层规律的最优数学表达，而模型的本质就是一个函数。

   评分说明：三条分述各有侧重，缺少「规则写不完 → 难以泛化」这条因果链，本题最高给 10 分。（001 P2、P4、P5、P6；002 P7、P9）

2. **总起（3分）：** 课件用偏差、方差、噪声三项刻画泛化误差，并以学习曲线作为诊断工具、以 6 条处方作为对症下药的依据。

   **分述①分解式与各项含义（4分）：** 令 $\overline{f}(x)=E_B[f(x;B)]$ 为学习算法的期望预测，则

   $$
   bias^{2}(x)=\left(\overline{f}(x)-y\right)^{2},\qquad var(x)=E_B\left[\left(f(x;B)-\overline{f}(x)\right)^{2}\right]
   $$

   $$
   E(f;B)=bias^{2}(x)+var(x)+\varepsilon^{2}
   $$

   其中噪声 $\varepsilon^{2}=E_B\left[\left(y_B-y\right)^{2}\right]$。课件 05 P31 的图注给出简化形式「**总体误差 = 偏差² + 方差**」。定义上，方差描述预测值的变化范围与离散程度（离其期望值的距离），偏差描述预测值（估计值）的期望与真实值之间的差距。

   **分述②推导与「噪声期望为零」（4分）：** 推导从 $E_B\left[(f(x,B)-y_B)^{2}\right]$ 出发，插入常数 $\overline{f}(x)$ 展开平方，把结果拆成三项：第一项为 $var(x)$；第二项中 $\overline{f}(x)$ 与 $y$ 均为常量，按期望的运算性质可从期望号中提出；交叉项 $2\left(\overline{f}(x)-y\right)E_B\left[(y-y_B)\right]$ 只有在假设**噪声的期望为零**时才化为 0。正是这一步用完了「噪声期望为零」这一假设，它是交叉项能消掉、分解能成立的前提。

   **分述③诊断规则（4分）：** 训练集误差和交叉验证集误差**近似**时 → **偏差／欠拟合**；交叉验证集误差**远大于**训练集误差时 → **方差／过拟合**。其成因是：随着模型复杂度增加，方差逐渐增大、偏差逐渐减小，在虚线所示的恰当复杂度处二者都适度，才能「适度拟合」。

   **分述④处方与 $\lambda$ 方向（4分）：** 治高方差（过拟合）三条：获得更多的训练实例、尝试减少特征的数量、尝试增加正则化程度 $\lambda$；治高偏差（欠拟合）三条：尝试获得更多的特征、尝试增加多项式特征、尝试减少正则化程度 $\lambda$。因此 $\lambda$ **增大治方差、减小治偏差**，与「正则化总是防过拟合」结合时要特别想清方向；正则化过度同样会导致欠拟合，适当才是目标。
   评分说明：分述①④各 4 分为重；漏掉「噪声期望为零」这一前提扣 2 分。（05 P30–P36）

**一、单选题**

1. **答案：B**
   解析：ANI（专用人工智能）是目前 AI 系统的定位——擅长处理特定领域的单一任务，表现卓越但缺乏灵活性，无法像人类一样跨领域迁移知识或「举一反三」。A、C 描述的都是 AGI（通用人工智能）：具备类人认知能力，能理解、推理并学习任何人类可完成的智力任务，跨越数学、艺术、科学等领域。课件强调当前 AI 仍属 ANI，不要把二者混用。（001 P3、P4）
2. **答案：B**
   解析：监督学习的定义是「有标签——对于输入数据 $X$ 能预测 $Y$」，其内部再分：分类（标签**离散**）与回归（标签**连续**）。因此两个层次不同，A 错。回归是「预测 $y$」，必须有标签，C 错；分类属监督学习而非无监督，D 错。⚠️易错点：分类与回归的界是**标签是否连续**，与输入变量是否连续无关。（01 P16–P17；02 P4）
3. **答案：C**
   解析：课件的三条结论是——① 从计算机求解梯度的复杂度来说 **MSE 优于 MAE**；② 若离群点是**实际数据或重要数据**，而且是应该被检测到的异常值，应该用 **MSE**；③ 若离群点仅代表**数据损坏或错误采样**，无须给予过多关注，应该选择 **MAE** 作为损失。A 项只说了 MSE 的优点，未回答本情境；B 项 RMSE 与 MSE 衡量的是完全相同的东西，与离群点处理策略无关；D 项 $R^{2}$ 不是损失函数。记忆口诀：梯度好算选 MSE，怕离群点选 MAE。（02 P30 演讲者备注）
4. **答案：B**
   解析：$J(f)$ 代表对**模型复杂度**的惩罚——模型越复杂 $J(f)$ 越大、越简单越小；$\lambda$ 是一个正的常数（正则化系数），用于平衡经验风险和模型复杂度。结构风险小的模型需要经验风险与复杂度同时小，因此对训练数据和测试数据都能有较好拟合。A 项把 $J(f)$ 的方向记反（这是课件标注的易错点）；C、D 项把 $J(f)$ 当成误差、把 $\lambda$ 当成学习率，与课件定义不符。（01 P25）
5. **答案：B**
   解析：$z=w^{T}x$ 是**线性部分**，范围为 $(-\infty,+\infty)$；$h(x)=\sigma(z)=\frac{1}{1+e^{-z}}$ 才是 $(0,1)$ 内的概率。二者不是同一个量，A 错；C、D 把两个量的角色对调。引入 Sigmoid 的原因正是：线性回归输出范围为 $(-\infty,+\infty)$，而分类预测结果需要 $[0,1]$ 的概率值。（03 P8、P9）
6. **答案：B**
   解析：求解分三步——似然函数 $\to$ 两边取对数（连乘号变连加号）得 $l(w)=\sum_{i=1}^{m}\left(y^{(i)}\log h(x^{(i)})+(1-y^{(i)})\log(1-h(x^{(i)}))\right)$ $\to$ 代价函数。注意**对数似然要最大化、代价函数要最小化，所以差一个负号**，故 $J(w)=-\frac{1}{m}l(w)$。A 项符号错；C 项漏了负号；D 项漏了 $\frac{1}{m}$。⚠️易错点：$l(w)$ 中两项之间是**加号**，$J(w)$ 取负号后展开才变成 $L(y,h(x))$ 形式的减号。（03 P14）
7. **答案：B**
   解析：判别模型由数据直接学习决策函数 $Y=f(X)$ 或条件概率分布 $P(Y|X)$，有限样本条件下建立判别函数、**不考虑样本的产生模型**，代表算法有线性回归、逻辑回归、感知机、决策树、支持向量机等。生成模型由训练数据学习联合概率分布 $P(X,Y)$ 再求 $P(Y|X)$，代表算法是朴素贝叶斯、HMM、深度信念网络（DBN）。A、C、D 三项均属生成模型。课件把「线性回归」列在判别模型一侧，按原文记忆。（04 P8）
8. **答案：C**
   解析：条件独立必须写成 $P(X|Z)=P(X|Y,Z)$ 的形式，即**在给定第三个变量后**条件才成立；等价写法为 $P(X,Y|Z)=P(X|Z)P(Y|Z)$。A 是无条件独立，不是本课件所说的「条件独立」；B、D 方向错误。⚠️易错点：写成无条件独立 $P(X,Y)=P(X)P(Y)$ 是错的。（04 P11）
9. **答案：B**
   解析：**方差**描述的是**预测值的变化范围、离散程度**，也就是离其期望值的距离，方差越大数据的分布越分散；**偏差**描述的是**预测值（估计值）的期望与真实值之间的差距**，偏差越大越偏离真实数据。A 项是偏差的定义；C 是划分比例概念；D 是错误率，均非方差。（05 P30）
10. **答案：D**
   解析：嵌入式特征选择 `SelectFromModel(estimator)` 从模型中自动选择特征，**任何具有 `coef_` 或者 `feature_importances_` 的基模型都可以作为 estimator 参数传入**——这是一道能力门槛，不是任意模型都行。封装式 `RFECV(estimator, scoring="r2")` 同样结合模型反复训练。（06 P13）

**二、填空题**

1. **答案：** 规则写不完（难以覆盖现实世界的变数，导致系统难以泛化）
   解析：早期 AI 走「专家系统」路线，工程师以「上帝视角」编写代码，核心困境正是**规则写不完**——现实世界充满变数，被咬一口、烂了一半或逆光下的苹果都需要重新编写规则，系统难以泛化。⚠️易错点：符号主义失败的原因不是「不够聪明」，答题时要落到「泛化」二字上。（001 P7）
2. **答案：** 优化算法
   解析：机器学习方法包含四大要素：**模型、损失函数、优化算法、模型评估指标**。其中优化算法指模型学习中的具体计算方法，本课程以**梯度下降法**为主要优化算法。（01 P20、P26）
3. **答案：** 特征
   解析：二者的梯度形式完全一样，都是 $\frac{\partial J(w)}{\partial w_j}=\frac{1}{m}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$，即「误差 × 特征」。⚠️易错点：**更新式相同、代价函数不同**——线性回归是平方和损失，逻辑回归是对数（交叉熵）损失。（02 P15；03 P15）
4. **答案：** 类别数量
   解析：$P_\lambda(C_k)=\frac{\sum_{i=1}^{N}I(y_i=C_k)+\lambda}{N+K\lambda}$ 中 $K$ 为**类别数量**、$A$ 为 $a_j$ 中**不同值的数量**，$I(\cdot)$ 为示性函数（成立取 1，否则取 0），通常 $\lambda=1$。（04 P24）
5. **答案：** 分层（stratify）
   解析：`stratify=y` 使测试集和训练集中各类别数据的比例与原始数据集比例一致；此外 `test_size=0.3` 表示 70% 训练／30% 测试，`random_state=12` 设定随机种子以固定划分结果，`shuffle=True` 提前打乱数据。（06 P10）

**三、简答题**

1. **总起（1分）：** 课件用五个等式界定机器学习与相邻领域的关系。
   **分述①模式识别（2分）：** **模式识别 = 机器学习**，两者主要区别在于前者从**工业界**发展起来，后者主要源自**计算机学科**；Bishop 在《Pattern Recognition And Machine Learning》开篇写道「模式识别源自工业界，而机器学习来自于计算机学科。不过，它们中的活动可以被视为同一个领域的两个方面」，可视为同一领域的两个方面。
   **分述②数据挖掘（2分）：** **数据挖掘 = 机器学习 + 数据库**；数据挖掘仅仅是一种**思考方式**，告诉我们应该尝试从数据中挖掘出知识，但**不是每个数据都能挖掘出金子**——「我尽管可能会挖出金子，但我也可能挖的是石头」。大部分数据挖掘中的算法是机器学习的算法在数据库中的优化，真正关键的是拥有数据挖掘思维、且对数据有深刻认识的人员。
   **分述③统计学习（2分）：** **统计学习 ≈ 机器学习**，两者高度重叠；统计学习者重点关注统计模型的发展与优化，偏**数学**；机器学习者更关注能够解决问题，偏**实践**，重点研究学习算法在计算机上执行的效率与准确性的提升。
   **分述④计算机视觉与语音识别（3分）：** **计算机视觉 = 图像处理 + 机器学习**（图像处理把图像处理为适合进入模型的输入，机器学习从图像中识别模式，如百度识图、手写字符识别、车牌识别）；**语音识别 = 语音处理 + 机器学习**（一般还会结合自然语言处理的相关技术，如苹果的语音助手 siri）。
   评分说明：五个对应式每个 1 分，解释部分共 7 分；缺「不是每个数据都能挖出金子」这一限定扣 1 分。（01 P10–P11 演讲者备注）

2. **总起（1分）：** 课件从五个维度对比两种求最优参数的方法。
   **分述①五个比较维度（6分）：** ① 是否需要选择学习率 $\alpha$：梯度下降**需要**，最小二乘法**不需要**；② 迭代次数：梯度下降需多次迭代，最小二乘法一次计算得出；③ 需要计算的中间量：梯度下降算**梯度**，最小二乘法算**矩阵逆** $\left(X^{T}X\right)^{-1}$；④ 特征数量 $n$ 大时：梯度下降也能较好适用，最小二乘法运算代价大（矩阵逆的时间复杂度为 $O(n^{3})$，通常 $n<10000$ 时还可接受）；⑤ 适用范围：梯度下降适用于各种类型的模型，最小二乘法只适用于线性模型，不适合逻辑回归等其他模型。
   **分述②取舍总结（3分）：** 梯度下降用「算得快、需调参」换取「通用」；最小二乘法用「一步到位」换来「只限线性模型 + 高维代价爆炸」。因此选择取决于两点：模型是否线性、特征数量是否大到让 $O(n^{3})$ 不可接受。
   评分说明：五个维度各 1 分，取舍总结须落到「以什么换什么」才算完整。（02 P18）

3. **总起（2分）：** 二者分别是逻辑回归的「线性部分」与「概率输出」，不可混为一谈。
   **分述①区别与联系（4分）：** $z=w^{T}x$ 是线性变换的结果，范围为 $(-\infty,+\infty)$；$h(x)=\sigma(z)=\frac{1}{1+e^{-z}}$ 把线性输出压到 $(0,1)$ 内成为概率。课件给出判决规则：$\sigma(z)\ge 0.5$ 预测 $y=1$，小于 0.5 预测 $y=0$。若表达式写作 $h(x)=z=w_0+w_1x_1+\cdots+w_nx_n+b=w^{T}x+b$，则 $b$ 可以融入 $w_0$，写成 $z=w^{T}x$。
   **分述②为何不能用最小二乘（4分）：** 课件在梯度下降与最小二乘法的比较表中明确写出：最小二乘法**只适用于线性模型，不适合逻辑回归模型等其他模型**，而梯度下降「适用于各种类型的模型」、特征数量大时也能较好适用。逻辑回归的代价函数是对数（交叉熵）损失，其闭式解并不具有 $w=\left(X^{T}X\right)^{-1}X^{T}Y$ 的形式，所以必须用梯度下降迭代求解。⚠️易错点：逻辑回归**不是**最小二乘法的解，不要把第 3 章的闭式解套到逻辑回归上。
   评分说明：须同时答出「$z$ 与 $h(x)$ 不是同一个量」和「最小二乘法只适用线性模型」两点。（03 P8、P18；02 P18）

4. **总起（2分）：** 混淆矩阵的行列方向决定了四个计数的含义，也决定了各指标分母的含义。
   **分述①行列含义与四个计数（2分）：** 行是**实际值**、列是**预测值**。实际 Positive × 预测 Positive 为 TP（正确肯定）；实际 Positive × 预测 Negative 为 FN（错误否定）；实际 Negative × 预测 Positive 为 FP（错误肯定）；实际 Negative × 预测 Negative 为 TN（正确否定）。⚠️易错点：看反行就会把 FP 当成 FN。
   **分述②Precision 与 Recall 的分母（3分）：** $Accuracy=\frac{TP+TN}{TP+TN+FP+FN}$，分母是**全部样本**；$Precision=\frac{TP}{TP+FP}$，分母是「**预测为正例**」的数量；$Recall=\frac{TP}{TP+FN}$，分母是「**实际为正例**」的数量。两者分母含义不同，是本章最经典的易错点。
   **分述③不平衡下为何不能只看 Accuracy（3分）：** 当少数类占比极低时，模型把绝大多数样本判为多数类也能得到很高的 Accuracy（分母含全部样本，少数类的错误被淹没），但少数类的识别能力其实很差；此时必须结合 Precision / Recall / F1 一起看。
   **分述④F1（3分）：** $F1=\frac{2\times Precision\times Recall}{Precision+Recall}$，它同时综合了 Precision 与 Recall，二者需兼顾时使用。
   评分说明：四个公式共 3 分，方向与理由共 7 分。（05 P12–P14）

**四、论述题**

1. **总起（3分）：** 朴素 = 假设特征之间条件独立，这是全章最核心的一条取舍。

   **分述①假设的形式化（3分）：** $P(X=x,Y=c_k)=\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)$（式(1)）；「条件独立」的严格写法是 $P(X|Z)=P(X|Y,Z)$，等价地 $P(X,Y|Z)=P(X|Z)P(Y|Z)$。其中 $c_k$ 代表类别、$k$ 代表类别个数。

   **分述②好处（3分）：** 课件明确指出这**是一个较强的假设**；由于这一假设，模型包含的条件概率数量**大为减少**，朴素贝叶斯法的学习与预测**大为简化**，因而**高效且易于实现**。在文本分类的多值伯努利事件模型中，链式法则本来是 $p(x^{(1)}|y)p(x^{(2)}|y,x^{(1)})p(x^{(3)}|y,x^{(1)},x^{(2)})\cdots$ 的逐项依赖，施加假设后每项只剩 $p(x^{(i)}|y)$，**连乘规模从指数级降到线性级**。

   **分述③代价（3分）：** 条件独立在现实中往往不成立（词与词、特征与特征之间普遍存在关联），因此朴素贝叶斯的缺点是**分类的性能不一定很高**。

   **分述④零概率问题与平滑的必要性（6分）：** 在 Sports 案例中，条件概率按词频估计，$P(game|Sports)=\frac{2}{11}$（Sports 类共 3 句、11 个词），但「close」不会出现在任何 Sports 样本中，即 $P(close|Sports)=0$——**只要有一个词的概率为 0，整个连乘就为 0**，两类概率会「同归于尽」。若不平滑，Sports 一侧的连乘直接归零，就可能误判为 Not Sports。因此引入**拉普拉斯平滑**：为每个计数加 1（永远不会为零），同时把可能单词的数量（词表共 14 个）加到除数中（使结果永远不会大于 1），得 $P(game|sports)=\frac{2+1}{11+14}$。平滑保证了每个值都在 0 到 1 范围内、最终和为 1 的概率性质，又避免了零概率，从而仍能正确判别（Sports 为 $2.76\times10^{-5}$，大于 Not Sports 的 $0.572\times10^{-5}$）。
   评分说明：分述①②③各 3 分，④为重难点；漏掉「指数级降到线性级」这一量化对比扣 1 分。（04 P10、P12、P15；04 P22–P25）

2. **总起（2分）：** sklearn 提供的评估与调优工具都建立在同一条链上——用交叉验证产生多个验证得分，用搜索在超参数空间里挑最优。

   **分述①网格搜索与随机搜索的异同（6分）：** 相同点：两者接口一致，都是 `.fit()` → `.best_params_`，替换类名即可切换。不同点：**搜索方式**——网格搜索在参数网格上**穷举**（如 `kernel`×`C` 的全组合），随机搜索在参数子空间中**随机采样**；**点的个数**——网格搜索取网格全组合，课件的随机搜索示例取 100 个点；**速度**——网格搜索慢、随机搜索时间耗费较少；**局部最优**——网格搜索不容易找到参数空间中的局部最优，随机搜索**更容易找到**；**分布**——网格搜索用列表即可，随机搜索可用 `scipy.stats` 的常见分布（如 `randint(1,20)`、`norm`、`uniform`）随机采样。

   **分述②二者的配合（4分）：** `cross_val_score(clf, X_train, y_train, cv=5, scoring='f1_weighted')` 对模型做 5 折交叉验证并给出各折评分；`GridSearchCV(svc, params, cv=5)` 则在参数网格上把「交叉验证」内建于调优过程，对每组参数组合做交叉验证并选出最优组合。两者的共同点是**都以交叉验证作为比较依据**，区别在于前者比较「模型」，后者比较「参数组合 × 模型」。

   **分述③与三分法的关系（3分）：** 训练／验证／测试集的分工是「验证集做模型选择与训练超参数（可选）、测试集测试已训练好模型的精确度」（机器学习常用 60/20/20 或 70/10/20）。而在 sklearn 中，`train_test_split` **只切出训练集与测试集两半**（如 70%/30%），不产生验证集；「三分法」是靠交叉验证或超参数搜索来实现的——即交叉验证把训练集内部再轮流切出验证部分，承担了验证集的角色，测试集则始终留作最终评估。
   评分说明：分述①6 分、②4 分、③3 分；③若未点明「`train_test_split` 只切两半」扣 1 分。（06 P25–P27；05 P4–P5）

**二、填空题**

1. **答案：** 两两互斥（$B_iB_j=\emptyset$，$i\neq j$）
   解析：全概率公式 $P(A)=\sum_{i=1}^{n}P(A|B_i)P(B_i)$ 成立的适用条件是 $B_iB_j=\emptyset\ (i\neq j)$ 且 $\bigcup_{i=1}^{n}B_i=\Delta$——即 $B_i$ 两两互斥且并集为全集。（01 P46）
2. **答案：** 学习率
   解析：$w=w-\alpha\frac{\partial J(w)}{\partial w}$，其中 $\alpha$ 为**学习率**，也称为**步长**。⚠️易错点：更新式中是**减号**，因为沿负梯度方向才使代价函数下降；$\alpha$ 太大会在最小值点附近振荡无法收敛，太小则收敛过慢。（02 P12）
3. **答案：** $w^{T}x$（即 $z$）
   解析：推导链为：先写几率 odds $=\frac{p}{1-p}$，取对数并令它等于线性输出 $log\frac{p}{1-p}=w^{T}x=z$，再求解 $p$ 得 $p=\frac{1}{1+e^{-w^{T}x}}$。必背：**「先线性、再取 Sigmoid」的来源就是把 $log\frac{p}{1-p}$ 直接赋成 $w^{T}x$**。⚠️易错点：$p$ 的范围是 $[0,1]$、$z$ 的范围是 $(-\infty,+\infty)$，两者不是同一个东西。（03 P9）
4. **答案：** 0-1
   解析：在独立性假设下，将输入 $x$ 分到后验概率最大的类 $y$，**后验概率最大等价于 0-1 损失函数时的期望风险最小化**。对应的 $0-1$ 损失为 $L(Y,f(X))=1$（$Y\neq f(X)$）、$0$（$Y=f(X)$）。（04 P13；01 P23）
5. **答案：** 真实值对其均值的方差
   解析：课件给出的另一种等价写法为 $R^{2}(y,\hat{y})=1-\frac{\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}/m}{\sum_{i=1}^{m}\left(y^{(i)}-\overline{y}\right)^{2}/m}=1-\frac{MSE}{Var}$，其中 $Var=\frac{1}{m}\sum_{i=1}^{m}\left(y^{(i)}-\bar{y}\right)^{2}$ 是真实值对其均值的方差，$MSE=\frac{1}{m}\sum\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}$。⚠️易错点：$R^{2}$ **越接近 1 越好**（与越小越好的 $MSE$ 方向相反）。（05 P11；02 P31）

**三、简答题**

1. **总起（2分）：** 线性回归虽简单，却包含了机器学习的核心思想，可用「五步流程 + 下山比喻」完整表达。
   **分述①训练流程五步（4分）：** **输入数据 → 计算预测 → 计算损失 → 计算梯度 → 更新参数**。每完成一轮循环参数就更接近一点，经过多轮迭代模型逐渐收敛到最优解。
   **分述②下山比喻四步（3分）：** ① **感知坡度（计算梯度）**——盲人用脚探知当前所处的坡度方向，确定哪里是下坡；② **迈出一小步（更新参数）**——顺着最陡峭的下坡方向（**负梯度方向**）迈出一步；③ **循环往复（迭代优化）**——在新位置继续感知坡度，继续向下走；④ **到达谷底（模型收敛）**——当走到再也没有下坡路的地方，即认为到达了最低点。
   **分述③比喻与概念的对应（3分）：** 山的当前高度 ↔ **损失函数的值 (Loss)**；下坡的方向 ↔ **梯度 (Gradient，即导数)**；每一步迈多大 ↔ **学习率 (Learning Rate)**。
   评分说明：三部分各占相应分值；漏掉「负梯度方向」这一限定扣 1 分。（003 P1；知识正文 1.9.5）

2. **总起（1分）：** 偏导推导共三步，核心是链式法则与「$w_j$ 线性、求和只剩一项」。
   **分述①第一步（3分）：** 把代价函数写成单样本形式并套链式法则：$\frac{\partial}{\partial w_j}J(w)=\frac{\partial}{\partial w_j}\frac{1}{2}\left(h(x^{(i)})-y^{(i)}\right)^{2}=\frac{1}{2}\cdot 2\left(h(x^{(i)})-y^{(i)}\right)\cdot\frac{\partial}{\partial w_j}\left(h(x^{(i)})-y^{(i)}\right)=\left(h(x^{(i)})-y^{(i)}\right)\cdot\frac{\partial}{\partial w_j}\left(h(x^{(i)})-y^{(i)}\right)$。
   **分述②第二步（3分）：** 代入 $h(x)$ 的展开式 $h(x^{(i)})=\sum_{k=0}^{n}w_kx_k^{(i)}$，得 $\left(h(x^{(i)})-y^{(i)}\right)\cdot\frac{\partial}{\partial w_j}\left(\sum_{k=0}^{n}w_kx_k^{(i)}\right)$。（课件此处原文写作 $\sum_{i=0}^{n}w_ix_i^{(i)}-y^{(i)}$，求和下标 $i$ 与样本上标 $(i)$ 撞名——**课件此处存疑**，按正确写法整理；因 $\frac{\partial}{\partial w_j}(-y^{(i)})=0$，结果不受影响。）
   **分述③第三步与更新式（3分）：** $w_j$ 是线性的且 $\frac{\partial w_k}{\partial w_j}=\delta_{jk}$，故求和只剩 $k=j$ 一项，得 $\frac{\partial}{\partial w_j}J(w)=\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$；参数更新式为 $w_j:=w_j-\alpha\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$。必背：**逻辑回归与线性回归的梯度形式完全一样——「误差 × 特征」。**
   评分说明：三步各 3 分，末步的更新式必须写出。（02 P15–P16）

3. **总起（1分）：** 推导共三步，关键在第三步的同类项合并。
   **分述①第一步（4分）：** 把 $h(x^{(i)})$ 用 Sigmoid 的表达式代入并化简：$y^{(i)}\log\left(\frac{1}{1+e^{-w^{T}x^{(i)}}}\right)+\left(1-y^{(i)}\right)\log\left(1-\frac{1}{1+e^{-w^{T}x^{(i)}}}\right)=-y^{(i)}\log\left(1+e^{-w^{T}x^{(i)}}\right)-\left(1-y^{(i)}\right)\log\left(1+e^{w^{T}x^{(i)}}\right)$。
   **分述②第二步（4分）：** 代入代价函数并对 $w_j$ 求导，得 $-\frac{1}{m}\sum_{i=1}^{m}\left(-y^{(i)}\frac{-x_j^{(i)}e^{-w^{T}x^{(i)}}}{1+e^{-w^{T}x^{(i)}}}-(1-y^{(i)})\frac{x_j^{(i)}e^{w^{T}x^{(i)}}}{1+e^{w^{T}x^{(i)}}}\right)$。
   **分述③第三步与关键（3分）：** 再代入 $h(x^{(i)})=\frac{1}{1+e^{-w^{T}x^{(i)}}}$ 合并同类项，得 $\frac{\partial}{\partial w_j}J(w)=\frac{1}{m}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$。**关键就是 $g'(z)=g(z)(1-g(z))$**——第二步那一堆指数分式之所以能塌缩成一个 $\left(h(x^{(i)})-y^{(i)}\right)$，正是这条 Sigmoid 求导性质的直接后果，也是它在逻辑回归里的唯一用途。
   评分说明：三步各占分值；不点明 $g'(z)=g(z)(1-g(z))$ 这一关键扣 2 分。（03 P16–P17；03 P10）

4. **总起（2分）：** 二者都依赖「用多折数据反复评估」，但一个比较模型、一个比较参数组合。
   **分述①`cross_val_score` 的作用与调用（3分）：** `from sklearn.model_selection import cross_val_score`，`scores = cross_val_score(clf, X_train, y_train, cv=5, scoring='f1_weighted')`——使用 5 折交叉验证对模型进行评估，评分函数为 F1 值，返回的是模型在各折上的得分。
   **分述②`GridSearchCV` 的作用与调用（3分）：** `from sklearn.model_selection import GridSearchCV`，`grid_search = GridSearchCV(svc, params, cv=5)`，`grid_search.fit(X_train, y_train)`，结果取 `grid_search.best_params_`——在参数网格上进行**穷举搜索**，方法简单但搜索速度慢，且不容易找到参数空间中的局部最优。
   **分述③共同点（2分）：** 二者都接受 `cv` 参数、都以交叉验证作为比较依据、接口都是 `.fit()` 后读取结果，替换类名即可在「评估一个模型」与「搜索一组超参数」之间切换。补充：sklearn 还提供了带交叉验证功能的模型类，如 `LassoCV`、`LogisticRegressionCV`，这些类同样包含 `cv` 参数。
   评分说明：三部分各占分值；须写明 `cv=5` 是 5 折交叉验证。（06 P25–P26）

**四、论述题**

1. **总起（3分）：** 任何机器学习方法都可拆成四个部件，缺一不可：模型、损失函数、优化算法、模型评估指标（01 P20）。

   **分述①模型（3分）：** 机器学习首先要考虑使用**什么样的模型**。模型类别大致有两种：**概率模型**与**非概率模型**。在监督学习中概率模型写作 $P(y|x)$、非概率模型写作 $y=f(x)$；在无监督学习中分别为 $P(z|x)$ 与 $z=f(x)$（注意输出的记号是 $z$）。按是否建模概率划分，概率模型的典型算法有决策树、朴素贝叶斯、隐马尔科夫模型、高斯混合模型；非概率模型有感知机、支持向量机、KNN、AdaBoost、K-means、神经网络，并可再按判别函数线性与否分为线性模型（感知机、线性 SVM、KNN、K-means）与非线性模型（核 SVM、AdaBoost、神经网络）。

   **分述②损失函数（3分）：** 损失函数值越小，模型性能越好。课件给出四种常见损失函数：$0-1$ 损失、平方损失、绝对损失、对数损失。给定一个数据集，将**训练数据集的平均损失**称为**经验风险**，据此可构建全局损失函数 $\underset{f}{\min}\ \frac{1}{N}\sum_{n=1}^{N}L(y_n,f(x_n))$；当样本数量不足时，单纯最小化经验风险会导致**过拟合**，为此加上控制模型复杂度的**正则项 $J(f)$**，得到结构风险最小化准则 $\underset{f}{\min}\ \frac{1}{N}\sum_{n=1}^{N}L(y_n,f(x_n))+\lambda J(f)$。

   **分述③优化算法（3分）：** 算法指模型学习中的**具体计算方法**；基于参数模型构建的统计学习问题都是最优化问题，它们都具有**显式的解析解**。现有优化方法主要有梯度下降法、牛顿法、拟牛顿法、ADAM 等等，本课程以**梯度下降法**作为主要的优化算法。

   **分述④模型评估指标与「为什么不能只看训练误差」（6分）：** 当损失函数给定时，将基于模型**训练数据的误差 (Training Error)** 和**测试数据的误差 (Testing Error)** 作为模型评估的标准，测试误差定义为 $E_{test}=\frac{1}{N'}\sum_{n=1}^{N'}L(y_n,\hat{f}(x_n))$（$N'$ 为测试数据数量，$y_n$ 为真实标签、$\hat{f}(x_n)$ 为预测标签）。**一般来说，若我们模型学习的效果好，则训练误差和测试误差接近一致**——因此评估模型好坏要看**训练误差与测试误差是否接近一致**，而不是训练误差越小越好。若只看训练误差，会把「把训练集背下来、丢掉预测新数据能力」的**过拟合**模型误判为最优模型。
   评分说明：分述①②③各 3 分、④为重难点 6 分；漏掉「训练误差与测试误差接近一致」这一判据扣 2 分。（01 P20–P27）

2. **总起（2分）：** 推导由「贝叶斯定理」与「条件独立假设」两个动作叠加而成，再利用分母与类别无关把后验比较化为连乘比较。

   **分述①符号约定（2分）：** 训练数据集 $T=\{(x_1,y_1),(x_2,y_2),\ldots,(x_n,y_n)\}$，由 $P(X,Y)$ 独立同分布产生；其中 $X=\{x_1,x_2,\ldots,x_n\}$ 为 $n$ 维向量的集合，$Y=\{c_1,c_2,\ldots,c_k\}$，$K$ 为类别数。

   **分述②式(2)：贝叶斯定理给出后验（3分）：** 对给定的输入 $x$，计算后验概率分布并将后验概率最大的类作为输出：

   $$
   P(Y=c_k|X=x)=\frac{P(X=x,Y=c_k)\,P(Y=c_k)}{\displaystyle\sum_{k=1}^{K}P(X=x,Y=c_k)\,P(Y=c_k)}
   $$

   **分述③式(1)：施加条件独立假设（3分）：** 朴素贝叶斯假设给定类别时各特征条件独立，即 $P(X=x,Y=c_k)=\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)$，代入式(2) 得

   $$
   P(Y=c_k|X=x)=\frac{\displaystyle\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)}{\displaystyle\sum_{k=1}^{K}\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)}
   $$

   **分述④分母可约与分类器式（5分）：** 分母是对**所有类求和后**得到的整体归一化项（它不是「每个类都一样」的逐项常数），但正因为它与当前比较的类别无关，取 $\arg\max$ 时仍然可以整体约去，于是**贝叶斯分类器**可以表示为

   $$
   y=f(x)=\arg\max_{c_k}\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)
   $$

   等价的判别准则写法是 $y=\arg\max_{c_k}P(Y=c_k)\prod_{j=1}^{n}P\left(X_j=x^{(j)}|Y=c_k\right)$（只是先验项与连乘项的书写顺序不同）；**后验概率最大等价于 0-1 损失函数时的期望风险最小化**，这为该判别准则提供了理论依据。
   评分说明：四部分各占分值；④若未说明「分母是整体归一化项但与类别无关」扣 1 分。（04 P13–P17）

2. **答案：C**
   解析：$R^{2}(y,\hat{y})=1-\frac{\sum\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}}{\sum\left(y^{(i)}-\bar{y}\right)^{2}}=\frac{SSR}{SST}=1-\frac{SSE}{SST}$，**$R^{2}$ 越接近于 1，说明模型拟合得越好**；而 $MSE=\frac{1}{m}\sum\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}$ 是越小越好。⚠️易错点：$R^{2}$ 与 $MSE$ 在同一批数据下满足 $R^{2}=1-\frac{MSE}{Var}$，因此两者方向相反，不要记混。（02 P31）
3. **答案：A**

1. **答案：** 接近一致
   解析：一般来说，若我们模型学习的效果好，则**训练误差和测试误差接近一致**。⚠️易错点：评估模型好坏要看训练误差与测试误差是否接近一致，而不是训练误差越小越好。（01 P27）
2. **答案：** 误差平方和（真实值与预测值之差的平方和）
   解析：$SSE=\sum_{i=1}^{m}\left(y^{(i)}-\hat{y}^{(i)}\right)^{2}$；与之配套的还有 $SSR=\sum_{i=1}^{m}\left(\hat{y}^{(i)}-\bar{y}\right)^{2}$（回归平方和）与 $SST=\sum_{i=1}^{m}\left(y^{(i)}-\bar{y}\right)^{2}$（总平方和），满足 $R^{2}=\frac{SSR}{SST}=1-\frac{SSE}{SST}$。（02 P31）
3. **答案：** 过拟合
   解析：正则化的目的是为了防止过拟合，课件给出的逻辑回归正则化代价函数为 $J(w)=\frac{1}{m}\sum_{i=1}^{m}\left[\cdots\right]+\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^{2}$；三种正则化强度下的模型状态为：没有正则化→**过拟合**，正则化过度→**欠拟合**，适当的正则化→目标状态。（03 P18）
4. **答案：** 更容易找到参数空间中的局部最优
   解析：网格搜索在参数网格上**穷举**，方法简单但搜索速度慢（超参数较多时），且**不容易**找到参数空间中的局部最优；随机搜索在参数子空间中**进行随机搜索**，时间耗费较少、**更容易找到局部最优**，并可从 `scipy.stats` 的常见分布（如正态分布 `norm`、均匀分布 `uniform`）中随机采样。（06 P26、P27）
5. **答案：** `predict_proba`
   解析：`predict(X_test)` 返回每个样本的**预测类别标签**；`predict_proba(X_test)` 返回每个样本属于各类的**概率**，用于画 ROC/PR 曲线、调分类阈值、与其他模型比较。⚠️易错点：只有**支持输出概率**的分类器才有 `predict_proba`；`y_pred` 是标签、`y_prob` 才是概率。（06 P16）

1. **总起（2分）：** 课件对机器学习的能力边界给出了明确限定。
   **分述①可以解决（4分）：** 机器学习可以解决**给定数据的预测问题**，三个环节依次为：第 1 步**数据清洗／特征选择**；第 2 步**确定算法模型／参数优化**；第 3 步**结果预测**。
   **分述②不能解决（4分）：** **大数据存储／并行计算**——属于工程与系统层面的问题，不是机器学习的任务；**做一个机器人**——属于硬件与控制系统的范畴。
   评分说明：⚠️易错点：不要把机器学习的能力边界夸大；若只答「能预测」而未写出三环节，扣 2 分。（01 P11）

2. **总起（2分）：** 三种正则化的区别在于「往损失函数里加什么」以及「谁负责强度、谁负责比例」。
   **分述①L1 正则化（Lasso 回归）（3分）：**

   $$
   J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}+\lambda\sum_{j=1}^{n}|w_j|
   $$

   加入的是权值向量 $w$ 的**绝对值之和**，功能是使权重**稀疏**（解更靠近某些轴，其余的轴为 0）。

   **分述②L2 正则化（Ridge 岭回归）（3分）：**

   $$
   J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}+\lambda\sum_{j=1}^{n}w_j^{2}
   $$

   加入的是权值向量 $w$ 的**平方和**，功能是使权重**平滑**（解更靠近原点，降低参数范数的总和）。

   **分述③弹性网络与两个参数（2分）：**

   $$
   J(w)=\frac{1}{2}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)^{2}+\lambda\left(\rho\cdot\sum_{j=1}^{n}|w_j|+(1-\rho)\cdot\sum_{j=1}^{n}w_j^{2}\right)
   $$

   其中 $\lambda>0$ 为**正则化系数**，调整正则化项与训练误差的比例——$\lambda$ 越大正则化越强、治方差（过拟合），$\lambda$ 越小则更易欠拟合；$1\ge\rho\ge 0$ 为**比例系数**，调整 L1 正则化与 L2 正则化的比例，$\rho=1$ 退化为纯 L1、$\rho=0$ 退化为纯 L2。
   评分说明：三式各占分值，作用方向各 1 分；补充「课件三式的求和均从 $j=1$ 开始、不含偏置项 $w_0$（课件此处未说明是有意为之还是笔误——**课件此处存疑**）」可得 1 分。（02 P27、P28）

3. **总起（2分）：** 三种分类器的区别只在于「对哪个分布建模」，训练与预测的流程完全一样（04 P27）。
   **分述①三种分类器及其分布假设（4分）：** `GaussianNB` 假设特征条件概率分布服从**高斯分布（正态分布）**，是最常用的贝叶斯分类器；`MultinomialNB` 假设服从**多项式分布**；`BernoulliNB` 假设服从**二项分布**。
   **分述②GaussianNB 的公式与最本质特点（4分）：** 高斯条件概率为

   $$
   P\left(X^{(j)}|y=c_k\right)=\frac{1}{\sqrt{2\pi\sigma_k^{2}}}\exp\left(-\frac{\left(X^{(j)}-\mu_k\right)^{2}}{2\sigma_k^{2}}\right)
   $$

   最本质的区别在于 $\mu_k$、$\sigma_k^{2}$ 带**类别下标 $k$**，即**每类有各自的均值与方差**。

   **分述③需要估计的参数（2分）：** 由 `fit` 用训练数据估计各类的 $\mu_k$、$\sigma_k$，其中方差为 $\sigma^{2}=\frac{\sum(X-\mu)^{2}}{N}$；随后 `predict` 用分类器式输出类别、`_score` 给出评分。
   评分说明：分布假设 4 分、公式与下标 4 分、参数估计 2 分。（04 P27、P29）

4. **总起（2分）：** 诊断看训练误差与验证误差的**相对关系**，处方则按诊断结论对症下药。
   **分述①诊断规则（4分）：** 训练集误差和交叉验证集误差**近似**时 → **偏差／欠拟合 (Underfitting)**；交叉验证集误差**远大于**训练集误差时 → **方差／过拟合 (Overfitting)**。课件图中三者标注为 Underfitting / Good fit / Overfitting。
   **分述②治高方差的三条（3分）：** 获得更多的训练实例；尝试减少特征的数量；尝试**增加**正则化程度 $\lambda$。
   **分述③治高偏差的三条（3分）：** 尝试获得更多的特征；尝试增加多项式特征；尝试**减少**正则化程度 $\lambda$。
   **分述④$\lambda$ 方向提醒（3分）：** $\lambda$ **增大治方差、减小治偏差**；与「正则化总是防过拟合」结合时要特别想清方向。补充理解：随着模型复杂度增加，方差逐渐增大、偏差逐渐减小，在虚线处（最恰当的复杂度）二者都适度，才能「适度拟合」。
   评分说明：诊断 4 分、处方各 3 分、方向提醒 3 分。（05 P35、P36）

**四、论述题**

1. **总起（3分）：** 逻辑回归 = 线性模型 + Sigmoid，是可解释性最强的二分类器，其工作链条完整而闭合。

   **分述①为什么需要 Sigmoid（3分）：** 线性回归的函数 $h(x)=z=w^{T}x$ 范围是 $(-\infty,+\infty)$，而**分类预测结果需要得到 $[0,1]$ 的概率值**——这正是引入 Sigmoid 的原因。若写为 $h(x)=z=w_0+w_1x_1+\cdots+w_nx_n+b=w^{T}x+b$，则 $b$ 可以融入 $w_0$，写成 $z=w^{T}x$。

   **分述②从 odds 推出 Sigmoid（4分）：** 在二分类模型中，事件的几率 odds 是事件发生与不发生的概率之比 $\frac{p}{1-p}$（其中 $p\in[0,1]$）。取对数并令它等于线性输出：$log\frac{p}{1-p}=w^{T}x=z$；求解 $p$ 得 $p=\frac{1}{1+e^{-w^{T}x}}=\frac{1}{1+e^{-z}}$。必背：**「先线性、再取 Sigmoid」的来源就是把 $log\frac{p}{1-p}$ 直接赋成 $w^{T}x$**。同时记 $g'(z)=g(z)(1-g(z))$，它是后续求导能塌缩的关键。

   **分述③判决规则与代价函数来源（4分）：** 判决规则：$\sigma(z)\ge 0.5$ 预测 $y=1$，小于 $0.5$ 预测 $y=0$。代价函数由似然出发：似然函数 → 两边取对数（连乘号变连加号）得对数似然 $l(w)$ → 取负号并除以 $m$ 得 $J(w)=-\frac{1}{m}l(w)$，即交叉熵（对数损失）代价函数。⚠️易错点：对数似然要最大化、代价函数要最小化，所以差一个负号；$l(w)$ 中两项之间是加号，取负号展开后才变成 $L(y,h(x))$ 形式的减号。

   **分述④梯度更新式及其与线性回归的联系（3分）：** 代价函数对 $w_j$ 求导得 $\frac{\partial}{\partial w_j}J(w)=\frac{1}{m}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$，故更新式为 $w_j:=w_j-\alpha\frac{1}{m}\sum_{i=1}^{m}\left(h(x^{(i)})-y^{(i)}\right)x_j^{(i)}$——**与线性回归的批量梯度下降更新式长得一模一样**。但⚠️易错点：**更新式相同、代价函数不同**（一个是平方和损失、一个是对数损失）；且逻辑回归**不能**用最小二乘法求解，因为最小二乘法只适用于线性模型。联系在于「线性部分 $w^{T}x$ 与梯度形式」，区别在于「输出经 Sigmoid 压成概率」与「用交叉熵而非平方和度量误差」。

   **分述⑤「输出概率、阈值可调」的实际价值（3分）：** 因为输出的是每个样本的**概率分数**，可以很容易地按阈值划分（大于某阈值是一类，小于某阈值是另一类）。这带来三方面实际价值：① 可按业务对两类错误的不同代价灵活调阈值（代价敏感场景）；② 可画出 ROC/PR 曲线横向比较模型；③ 可与上游风控/推荐系统按风险等级分档对接——这是逻辑回归区别于硬分类模型的地方。
   评分说明：五部分各占分值；④⑤为易错与得分点。（03 P8–P19；02 P14、P15）

2. **总起（3分）：** 类别不平衡的分类任务，评价与调优必须围绕「少数类是否被识别」来组织。

   **分述①数据划分（3分）：** 按训练／验证／测试集划分：训练集确定拟合曲线参数；验证集（开发集）做模型选择与训练超参数，**可选**；测试集测试已训练好模型的精确度。比例：机器学习常用 60%/20%/20% 或 70%/10%/20%；深度学习 98%/1%/1% 的前提是**百万级数据**，小数据集照搬会导致验证集过小。数据量不足时更依赖**交叉验证**（训练 $k$ 个模型 → 算交叉验证误差 → 选取代价函数值最小的模型 → 算测试集上的推广误差），注意交叉验证误差用于选模型、推广误差是对测试集算的，两者不要混称。

   **分述②指标选择（4分）：** $Accuracy=\frac{TP+TN}{TP+TN+FP+FN}$ 的分母是全部样本，在正负比例悬殊时少数类的错误会被淹没，从而**高估**模型；必须配合 $Precision=\frac{TP}{TP+FP}$（分母为「预测为正例」的数量）、$Recall=\frac{TP}{TP+FN}$（分母为「实际为正例」的数量）与 $F1=\frac{2\times Precision\times Recall}{Precision+Recall}$。选择取决于业务代价：漏掉正例代价高（如风控）就以 Recall 为主并牺牲部分 Precision；误报代价高则以 Precision 为主。混淆矩阵行是实际值、列是预测值，看反行会把 FP 当成 FN。

   **分述③不平衡的处理方法及其代价（4分）：** **采样**（分欠采样、过采样和综合采样）——其中 **SMOTE** 是过采样中比较常用的一种，思想是**合成新的少数类样本，而不是简单地复制样本**；**代价敏感学习**——为不同类别的样本提供不同的权重，让模型更专注于少类样本，代价是**提高对少类样本分类的查全率、但降低查准率**（会把很多多类样本分类为少类样本），两者存在权衡。

   **分述④定位问题并对症下药（4分）：** 用学习曲线诊断：训练误差与交叉验证误差**近似** → 高偏差/欠拟合 → 获取更多特征、增加多项式特征、减小 $\lambda$；交叉验证误差**远大于**训练误差 → 高方差/过拟合 → 获得更多训练实例、减少特征数量、增大 $\lambda$。其理论依据是泛化误差的分解 $E(f;D)=bias^{2}(x)+var(x)+\varepsilon^{2}$：随着模型复杂度增加，方差逐渐增大、偏差逐渐减小，在「适度拟合」处取得平衡。若要进一步压缩方差，还可叠加 Dropout（功能类似于 $L_2$ 正则化，**训练阶段使用、测试阶段不使用**，keep-prob=0.5 为常用取值）与 Early stopping（提早停止训练，无需尝试 $L_2$ 超参数 $\lambda$ 的很多值）。
   评分说明：四部分各占分值；②中「Accuracy 会高估」与③中「加权少类→查全率↑、查准率↓」是两处关键得分点。（05 P4–P8、P12–P14、P32–P36；06 P10）

**一、单选题**

1. **答案：C**
   解析：「学习驱动（联结主义）」放弃人工编写规则，让机器像人类一样去「看」、去「学」，通过从海量数据中自主归纳特征而非依赖预设逻辑，其**成功关键是数据驱动与自主归纳**——不再依赖人类的「上帝视角」，机器从数据中自我进化，具备处理模糊、复杂现实信息的能力。A 项描述的正是与之对立的「规则驱动（符号主义）」路线；B 项把「算力」误当成该路线的成功关键（算力是 AI 爆发的两块基石之一，但不是「两条路线的分野」所在）；D 项是规则驱动路线的失败尝试。（001 P7）
2. **答案：B**
   解析：多特征线性回归中 $w_3$（距地铁）取负号，表示**离地铁越远，房价越低**。四个权重的符号含义为：$w_1$（面积）正——面积越大房价越高；$w_2$（楼层）正——中高楼层通常更贵；$w_3$（距地铁）负；$w_4$（房龄）负——房子越老房价越低。A 项是 $w_4$ 的含义；C、D 项符号与课件相反。（003 P1）
3. **答案：C**
   解析：课件通过「数据大小—准确率」图指出，**各种不同算法在输入的数据量达到一定级数后，都有相近的高准确度**，于是诞生了机器学习界的名言：「成功的机器学习应用不是拥有最好的算法，而是拥有最多的数据！」。A 项「完全相同」过于绝对且与图不符；B 项把数据量与算法复杂度混为一谈；D 项与名言相反。（01 P77；02 P25；05 P23）
4. **答案：D**
   解析：课件对比表明确：最小二乘法在「特征数量 $n$ 大时」**运算代价大**（需要计算的中间量是矩阵逆 $\left(X^{T}X\right)^{-1}$，其计算时间复杂度为 $O(n^{3})$，通常 $n<10000$ 时还是可以接受的）；而梯度下降在「特征数量 $n$ 大时也能较好适用」，且「适用于各种类型的模型」。A 项忽略了 $O(n^{3})$ 的代价；C 项错在两者代价函数相同（都是平方和损失）、只是求解方式不同；B 项逻辑回归是分类问题，此处模型已给定为线性回归模型。（02 P18）
5. **答案：B**
   解析：多项式回归的引入理由是**现实中的数据并不总是沿一条直线分布**——例如当房价随面积的增长先慢后快时，直线就无法很好地拟合，此时可引入 $\hat{y}=w_1x+w_2x^2+\cdots+w_dx^d+b$；当 $d=1$ 时就是普通线性回归，$d=2$ 时拟合出的是一条抛物线，阶数越高曲线越灵活。A 项把「回归」与「分类」的界搞反；C 项输出概率是逻辑回归/深度学习的特征；D 项与课件无关。（003 P1）
6. **答案：A**
   解析：$g'(z)=g(z)\left(1-g(z)\right)$，由于 $g(z)\in(0,1)$，故 $g'(z)\leqslant \frac{1}{4}$，且在两端（$z\to\pm\infty$）趋于 0；由 AM-GM 可知等号在 $g(z)=\frac{1}{2}$（即 $z=0$）时成立，此时导数最大为 $\frac{1}{4}$，而非 1。C 项把最大值说成 1；D 项方向相反。补充：这一性质是**深层网络用 Sigmoid 会出现梯度消失**的直接后果（该推论课件未展开）。（03 P10）
7. **答案：C**
   解析：多值伯努利事件模型中，未施加假设时按链式法则为 $p(x^{(1)}|y)p(x^{(2)}|y,x^{(1)})p(x^{(3)}|y,x^{(1)},x^{(2)})\cdots p\left(x^{(50000)}|y,x^{(1)},\ldots,x^{(49999)})\right)$，规模为指数级；施加朴素贝叶斯假设（各词只依赖 $y$）后为 $p(x^{(1)}|y)p(x^{(2)}|y)p(x^{(3)}|y)\cdots p(x^{(50000)}|y)=\prod_{i=1}^{m}p(x^{(i)}|y)$，**连乘规模从指数级降到线性级**。这正是「朴素」假设带来的效率收益。（04 P12）
8. **答案：C**
   解析：贝叶斯公式 $P(Y|X)=\frac{P(X,Y)}{P(X)}=\frac{P(X|Y)P(Y)}{P(X)}$ 中，$P(X)$ 作为分母是「所有类共同的分母」；若它为 0，则分子也必然为 0，公式成为 $0/0$ 而无法计算。这也正是分类时**舍弃分母**这一做法的原因：由于分母对当前比较的类别无影响、约去后只剩相对大小关系，从而绕开了直接求 $P(X)$ 的困难与数值不稳定。（04 P6、P17）
9. **答案：C**
   解析：课件明确列出——**不需要做**归一化/标准化的模型有：决策树、基于决策树的 Boosting 和 Bagging 等集成学习模型（树模型）以及**朴素贝叶斯**，以上这些模型**对特征取值大小并不敏感**，一般不需要做。判据是「模型是否依赖特征的绝对尺度」——按阈值分裂、统计概率的模型不需要。A、B、D 三项把「不需要」的模型误当作「必须预处理」。⚠️易错点：树模型与朴素贝叶斯**不需要**归一化/标准化，这是「一刀切全做归一化」的常见反例。（05 P20；02 P21）
10. **答案：D**
   解析：sklearn 的统一 API 是「构建实例 → `fit` → `predict`/`transform`」；转换器（如 `StandardScaler`）多一步 `fit_transform`，一次完成拟合与转换：`scaler = StandardScaler()` 后 `scaler.fit_transform(X_train)`；而模型类如 `LinearRegression` 是 `lr = LinearRegression(normalize=True)` → `lr.fit(X_train, y_train)` → `lr.predict(X_test)`。B 项错误（`StandardScaler` 有 `fit`）；C 项错误（`LinearRegression` 支持 `predict`）；A 项错误（模型不需 `fit_transform`）。（06 P11、P14）

**二、填空题**

1. **答案：** 自动迭代优化
   解析：确定特征权重的三步为：① **数据驱动基石**——基于海量真实场景的历史数据构建模型训练的样本池；② **自动迭代优化**——算法自动调整参数权重，无需人工干预，通过反复迭代计算不断修正偏差、持续逼近目标函数的最优解；③ **锁定最优权重**——最终收敛至全局最优权重组合，精准量化每个特征的价值。（002 P15）
2. **答案：** 相关性
   解析：由于机器学习不是基于编程形成的结果，因此它的处理过程**不是因果的逻辑，而是通过归纳思想得出的相关性结论**。⚠️易错点：这是课件反复强调的限定语，不要把相关当因果。（00 P3；01 P74）
3. **答案：** 概率
   解析：逻辑回归的第四条优点是「方便输出结果调整」——因为输出的是**每个样本的概率分数**，可以很容易地对这些概率分数进行划分阈值（大于某个阈值的是一类，小于某个阈值的是一类）。这直接对应第 4 章 03 P8 的判决规则：逻辑回归天然输出概率，所以阈值可调，这是它区别于硬分类模型的地方。（03 P19）
4. **答案：** 示性
   解析：$I(\cdot)$ 为示性函数（成立取 1，否则取 0）。公式中 $K$ 表示**类别数量**、$D$ 表示 $a_j$ 中**不同值的数量**，通常 $\lambda=1$；类别先验的分母加 $K\lambda$，特征条件概率的分母加 $D\lambda$。加入平滑之后避免了概率为 0 的情况，又保证每个值都在 0 到 1 范围内、最终和为 1。（04 P24）
5. **答案：** 嵌入式
   解析：按是否用到模型划分：过滤式（Filter，`SelectKBest(score_func, k)`，保留得分排名前 $k$ 的特征）**不用模型**；封装式（Wrapper，`RFECV(estimator, scoring="r2")`，结合交叉验证的递归特征消除法）**用模型反复训练**；嵌入式（Embedded，`SelectFromModel(estimator)`）**直接用模型自身的权重或重要性**——任何具有 `coef_` 或者 `feature_importances_` 的基模型都可作为 estimator 传入。（06 P13）

**三、简答题**

1. **总起（2分）：** 模型式、吸收常数项、设计矩阵三者是一条连续的记号约定。
   **分述①符号约定（3分）：** $h(x)=w_0+w_1x_1+w_2x_2+\cdots+w_nx_n$，其目的是找到一条直线／平面或更高维的**超平面**，使得预测值与真实值之间的误差最小化。全章符号：$m$ 为训练集样本数量，$n$ 为特征数量，$x$ 为特征／输入变量，$y$ 为目标变量／输出变量，$(x^{(i)},y^{(i)})$ 为第 $i$ 个观察样本，$h$ 为学习算法的解决方案或假设（hypothesis），$\hat{y}=h(x)$ 为预测值。
   **分述②为何令 $x_0=1$（2分）：** 如果表达式写作 $h(x)=w_0+w_1x_1+\cdots+w_nx_n+b$，则 $b$ 可以融入到 $w_0$；设 $x_0=1$ 后模型才能写成纯线性组合 $h(x)=w_0x_0+w_1x_1+\cdots+w_nx_n=w^{T}X$。
   **分述③设计矩阵与 $w$ 的形状（3分）：** $X$ 为 $m$ 行 $n+1$ 列，$w$ 为 $n+1$ 行 1 列（包含了 $w_0$），$Y$ 为 $m$ 行 1 列；$X$ 的**第 1 列全是 1**，它不是原始特征，而是为承载 $w_0$ 而人为加入的 $x_0=1$。
   **分述④$x^{(i)}$ 与 $x_j^{(i)}$ 的区别（3分）：** $x^{(i)}$ 是特征矩阵中的**第 $i$ 行，是一个向量**（$n$ 维列向量）；$x_j^{(i)}$ 代表特征矩阵中**第 $i$ 行的第 $j$ 个特征**，是一个标量。例如第 2 个样本中 $x^{(2)}=[162.2,\ 31,\ 8,\ 118]$ 为四维列向量，而 $x_2^{(2)}=31$ 指的是「总层数」这一列。
   评分说明：⚠️易错点：课件 P7 把向量形式写作 $w^{T}X$，而 P9 的矩阵形式写作 $Xw$——单样本的向量形式是 $w^{T}x$，整体矩阵形式是 $Xw$，两者不要混用（**课件此处存疑**）；若指出这一点可得 1 分。（02 P6、P7、P9）

2. **总起（2分）：** 一对多是把多分类问题拆成一组二分类问题的做法。
   **分述①二分类的做法（2分）：** 数据按类型 1 与类型 2 划分，**先定义其中一类（例如用蓝色圆形数据）定义为类型 1，其余数据为类型 2**；二分类**只需要分类 1 次**，步骤为 ① → ②。
   **分述②一对多（One-vs-Rest）的做法（4分）：** 先定义其中一类为类型 1（正类），其余数据为负类（rest）；接下来**去掉类型 1 数据**，剩余部分再次进行二分类，分成类型 2 和负类；如此递推，步骤为 ① → ② → ③ → ……
   **分述③次数与「rest」角色（3分）：** 如果有 $n$ 类，那就需要分类 **$n-1$ 次**；**最后剩下的那一类充当了「rest」**，不需要单独训练分类器。⚠️易错点：$n$ 类需要训练 $n-1$ 个二分类器，不是 $n$ 个，也不是 1 个。
   **分述④与二分类对比（2分）：** 二分类只需 1 次划分、无「负类池」；一对多则是 $n-1$ 次划分、每次都把「其余所有类」当作统一的负类，最后一类天然成为 rest，代价是类别不平衡程度随类别数增加而加剧（可与 SMOTE／代价敏感学习等不平衡处理手段呼应）。
   评分说明：三部分各占分值；须答出 $n-1$ 次而非 $n$ 次。（03 P5、P6）

3. **总起（2分）：** 四个概率项各自回答不同的问题，方向不能混淆。
   **分述①四项含义与方向（4分）：** $P(Y|X)$ 是**后验概率**——看到 $X$ 后 $Y$ 成立的置信度；$P(X|Y)$ 是**似然度**——在 $Y$ 成立的前提下观测到 $X$ 的概率；$P(Y)$ 是**先验概率**——没有训练数据前 $Y$ 的初始概率；$P(X)$ 是**边际似然度**——与类别无关的证据项。⚠️易错点：$P(X|Y)$（似然度）与 $P(Y|X)$（后验概率）**方向相反，不是同一件事**，写公式时极易把条件符号搞反。记忆口诀：后验概率 =（似然度 × 先验概率）/ 边际似然度。
   **分述②分母可约（4分）：** 在比较各类后验大小时，$P(X)$ 是对**所有类求和后**得到的整体归一化项，与当前比较的类别无关，取 $\arg\max$ 时可整体约去，于是得到 $y=f(x)=\arg\max_{c_k}\prod_{j=1}^{n}P\left(X^{(j)}=x^{(j)}|Y=c_k\right)P(Y=c_k)$。案例中对应的一步是「舍弃除数」，只比较 $P(X|Sports)\times P(Sports)$ 与 $P(X|Not\ Sports)\times P(Not\ Sports)$。
   **分述③生成 vs 判别的建模对象差别（4分）：** **判别模型**由数据直接学习决策函数 $Y=f(X)$ 或条件概率分布 $P(Y|X)$，有限样本条件下建立判别函数，**不考虑样本的产生模型**，代表算法有线性回归、逻辑回归、感知机、决策树、支持向量机等；**生成模型**由训练数据学习**联合概率分布 $P(X,Y)$** 再求得 $P(Y|X)$，即估计 $P(X|Y)$ 和 $P(Y)$ 得到 $P(X,Y)=P(Y)P(X|Y)$ 再用于分类，代表算法是朴素贝叶斯、HMM、深度信念网络（DBN）。因此二者的差别不在「先验还是后验」，而在**建模对象是 $P(Y|X)$ 还是 $P(X,Y)$**。
   评分说明：三部分各占分值；③若未点出「建模对象」这一根本差别扣 2 分。（04 P6、P8、P17）

4. **总起（2分）：** 三集合的分工是把「调模型」与「评模型」在数据上物理隔开。
   **分述①各自职责（3分）：** **训练集 (Training Set)** 帮助我们训练模型，简单说就是通过训练集的数据让我们确定拟合曲线的参数；**验证集 (Validation Set，也叫开发集 Dev Set)** 用来做**模型选择 (model selection)**，即做模型的最终优化及确定的，用来辅助我们模型的构建，即**训练超参数**，**可选**；**测试集 (Test Set)** 为了测试已经训练好的模型的精确度。
   **分述②比例（2分）：** 机器学习：60%/20%/20% 或 70%/10%/20%；深度学习：98%/1%/1%（假设百万条数据）。
   **分述③分工的必要性（3分）：** 如果拿测试集去选超参数、反复用它评估不同方案，测试集的信息就「泄漏」进了模型选择过程，最终报出的精度会偏乐观而失去参考价值。因此验证集可被反复使用（用于调参），而测试集只在最后使用一次。⚠️易错点：验证集用于**模型选择/调超参数**（可选），测试集用于**最终评估**，二者不可互换。
   **分述④两个前提条件（3分）：** ① 深度学习 98/1/1 的前提是**百万条数据**——小数据集照搬会导致验证集过小；② `train_test_split` **只切出训练集与测试集两半**（如 70%/30%），不产生验证集，第 6 章的「训练/验证/测试」三分法在 sklearn 中靠**交叉验证或超参数搜索**实现——交叉验证把训练集内部再轮流切出验证部分、承担了验证集的角色。
   评分说明：四部分各占分值；④两项各 1.5 分。（05 P4；06 P10）

**四、论述题**

1. **总起（3分）：** 该主张混淆了「规则的来源」与「规律的承载形式」，在四个层面上都不成立。

   **分述①两条路线的对比（4分）：** 早期 AI 走 **01 规则驱动（符号主义）**路线，工程师以「上帝视角」编写代码，试图用严谨的逻辑规则定义世界的一切（如「如果 圆 且 红 且 有柄 → 苹果」）；**02 学习驱动（联结主义）**路线则放弃人工编写规则，让机器像人类一样去「看」、去「学」，通过从海量数据中自主归纳特征，而非依赖预设逻辑——其**成功关键是数据驱动与自主归纳**，不再依赖人类的「上帝视角」，机器从数据中自我进化，具备处理模糊、复杂现实信息的能力。

   **分述②「规则写不完」的困境（4分）：** 符号主义路线的核心困境是**规则写不完**——现实世界充满变数，被咬一口、烂了一半或逆光下的苹果都需要重新编写规则，系统**难以泛化**。⚠️易错点：早期符号主义的失败原因不是「不够聪明」，而是要落到**「泛化」**二字上。人类自身也印证了这一点：我们从未死记硬背苹果的「标准答案」，智能的核心不在「存储答案」而在「**提取规律**」。

   **分述③数据与算力是前提（4分）：** 机器模拟智能本质上是一场依赖「暴力计算」的模拟游戏，直到最近才集齐两块关键拼图：**01 海量数据 (Data)**——数据是智能学习的基石，没有足够的样本，模型便无法学会理解与生成；**02 超强算力 (Compute)**——GPU 与 TPU 等专用 AI 芯片让海量矩阵运算高效可行。数据为 AI 提供「养料」，算力为 AI 提供「引擎」，二者如同车之两轮、鸟之双翼，**缺一不可**。手工写规则既绕不开数据的缺失，也绕不开规则爆炸带来的算力与人力成本。

   **分述④模型／算法／权重三者的关系（2分）：** **算法 =「学习的方法」**，是构建模型的「设计师」，负责规划学习的路径；**模型 =「学习的结果」**，是算法的产出物，承载着学习到的规律用于预测。判定式为 $\text{总得分}=(W_1\times 特征_1)+\cdots+(W_n\times 特征_n)$，而**机器学习的训练过程，本质上就是不断调整这些权重参数，让模型的预测结果无限逼近真实情况的过程**。因此「谁定规则」的答案是算法与数据，而不是人。

   **分述⑤可行的替代路线（2分）：** 把「人工枚举规则」换成「人工设计框架 + 数据自动确定参数」：用训练数据拟合模型式（如 $h(x)=w_0+w_1x_1+\cdots+w_nx_n$，或更一般地 $P(y|x)$、$y=f(x)$），用损失函数度量误差、用优化算法迭代求参、用评估指标检验泛化效果；遇到过拟合则按「获得更多训练数据 → 降维 → 正则化 → 集成学习」的顺序处理。以垃圾邮件模型 1.0→3.0 为例，正是从「60% 概率盲猜」到「工作日/周末单一特征」再到「周末发送 + 文件大小 > 10KB」的**多维特征组合**（缺一不可），规则条数没有爆炸，判别能力却持续提升。
   评分说明：五部分各占分值；②与④是关键得分点。（001 P5、P7–P9、P15；002 P10、P11–P14）

2. **总起（2分）：** 本场景的三个硬约束——不平衡 99:1、50 万条数据、要求输出概率供分档——共同决定了方案。

   **分述①完整调用链（6分）：**
   - **加载数据**：`iris = datasets.load_iris()` 一类方式或从 Pandas 读入；sklearn 接受 NumPy arrays、Pandas 对象、SciPy 稀疏矩阵等，前提是**数据必须是数值型的**。记 `X` 为特征矩阵、`y` 为标签。
   - **数据划分**：`X_train, X_test, y_train, y_test = train_test_split(X, y, random_state=12, stratify=y, test_size=0.3)`——70% 训练／30% 测试；`stratify=y` 分层保证各集合类别比例与原始一致，**对不平衡数据尤为必要**；`random_state=12` 固定划分以保证可复现。若要调超参数，用 `cross_val_score(clf, X_train, y_train, cv=5, scoring='f1_weighted')` 做 5 折交叉验证承担验证集角色。
   - **预处理**：特征尺度差异大时先标准化——`scaler = StandardScaler()` 后 `scaler.fit_transform(X_train)`（Z-Score，处理后均值 0、方差 1）；线性模型（含逻辑回归）**需要**做，朴素贝叶斯**不需要**。
   - **模型**：`lr = LogisticRegression()`，然后 `lr.fit(X_train_scaled, y_train)`。
   - **预测**：`y_pred = lr.predict(X_test)` 得到标签；`y_prob = lr.predict_proba(X_test)` **得到概率分数**——这正是本题「供风控系统按风险等级设阈值」的硬要求。
   - **评价**：`from sklearn.metrics import ...`，分类侧用 `accuracy_score`、`precision_score`、`f1_score`、`confusion_matrix`、`classification_report`；回归侧（本场景不适用但需知道对应关系）用 `mean_absolute_error`、`mean_squared_error`、`r2_score`。
   - **超参数搜索**：`GridSearchCV(svc, params, cv=5)` 在参数网格上穷举（慢、不易找局部最优），或 `RandomizedSearchCV(svc, param_dist, n_iter=10)` 随机采样（时间耗费较少、**更容易找到局部最优**，分布可从 `scipy.stats` 如 `randint(1,20)` 采样）；结果取 `.best_params_`。

   **分述②指标选择（4分）：** 不选 Accuracy 的理由是其分母为**全部样本**，在 99:1 的比例下把绝大多数样本判为「不违约」即可得到约 0.99 的高分，少数类（违约）错误被彻底淹没，**高估**模型。应改用 $Precision=\frac{TP}{TP+FP}$、$Recall=\frac{TP}{TP+FN}$ 与 $F1=\frac{2\times Precision\times Recall}{Precision+Recall}$，并用 `confusion_matrix` 检查四个计数。进一步可考虑不平衡处理：SMOTE（**过采样**，合成新的少数类样本而非简单复制）或**代价敏感学习**（给少类更高权重，代价是查全率↑、查准率↓）。

   **分述③正则化设置与 $\lambda$ 方向（3分）：** 50 万条数据、特征多为 ID 类的场景容易高维稀疏、模型易过拟合，因此应**加入正则化** $J(w)=\frac{1}{m}\sum_{i=1}^{m}[\cdots]+\frac{\lambda}{2m}\sum_{j=1}^{n}w_j^{2}$。课件明确：**当 $\lambda$ 的值开始上升时，降低了方差**——即 $\lambda$ 增大治高方差（过拟合）、$\lambda$ 减小治高偏差（欠拟合）。目标状态是「适当的正则化」：没有正则化会过拟合，正则化过度会欠拟合，$\lambda$ 不是越大越好；具体取值应通过交叉验证 + 搜索确定，而非凭经验拍定。

   **分述④选逻辑回归而非朴素贝叶斯的理由（4分）：** 两者的根本差别在于**建模对象**——逻辑回归是**判别模型**，直接学习决策函数 $Y=f(X)$ 或 $P(Y|X)$，不考虑样本的产生模型；朴素贝叶斯是**生成模型**，须估计 $P(X|Y)$ 和 $P(Y)$ 得到联合分布 $P(X,Y)=P(Y)P(X|Y)$ 再求后验。结合三条课件结论：① 逻辑回归在**表达能力**上虽弱（不能自动做特征交叉），但本场景特征以 ID 类为主，线性加权恰恰适合——其优点第 2 条正是「训练时便于并行化、预测时只需线性加权，**适合处理海量 ID 类特征**」，对头部资源有更细致的描述且防止信息损失；② 本场景**明确要求输出概率供分档**，逻辑回归天然输出概率分数、可灵活划分阈值，而朴素贝叶斯要拿到概率还需额外计算归一化分母；③ 逻辑回归还可解释（从特征权重可见各特征影响）、资源占用小，契合风控的合规与内存约束。反过来讲，朴素贝叶斯的强项（高效、易实现、无需归一化）在 50 万条数据上并非瓶颈。
   评分说明：四部分各占分值；①调用链须覆盖划分、预处理、模型、概率输出、评价、搜索六环；④须落到「判别 vs 生成的建模对象」。（05 P12、P20、P35；06 P10、P14、P16、P23–P26；03 P19；04 P8）
